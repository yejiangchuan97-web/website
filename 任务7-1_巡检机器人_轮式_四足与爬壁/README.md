# 任务7-1：桥梁巡检三维现场

[打开实训页面](index.html) · [深色版](dark.html) · [返回任务目录](../README.md)

双击即可离线使用。Three.js 与所有程序、材质内联于 HTML；三维操作需要浏览器支持 WebGL。

## 本次重建

对照用户指定的任务6-3腻子打磨三维工坊，重新制作连续的桥梁现场。沿用蓝白界面、透视相机、实体倒角与自然阴影；桌面为16:9单屏工作台，手机采用上下排列。

同一座桥中包含桥面排水口、检修楼梯与桥台、钢梁检查面。三台机器人具有可近看的轮胎与悬挂、腿部关节、磁吸轮、相机云台和内部组件。可拖动旋转、滚轮缩放、切换全桥/跟随/部位/机体/相机视野，并拆开机体观察。

## 学生完成什么

| 检查点 | 到达与取证 | 管养后续 |
| --- | --- | --- |
| A01 桥面排水口 | 轮式平台巡视，记录排水口杂物与积水 | 模拟人员清理后同点复拍，证据确认后闭环 |
| B02 桥台侧面水迹 | 四足经过检修台阶，记录水迹位置与范围 | 来源尚未确认，继续跟踪 |
| C03 钢梁表面近查 | 本课磁吸爬壁机确认钢面和附着、连接独立防坠系绳后爬升 | 涂层线状异常交专业人员复核 |

四步任务为看现场、走到位、看清楚、留记录。错误平台在具体障碍前停下；学生可以按住前进或让平台沿路线移动。取景器由机器人真实光心渲染同一三维现场，水平转向、俯仰和补光改变实际照片。全景与细部影像分别用于定位和辨认现象。

不合格照片也保留原始快照与参数；后续调镜头不会修改旧证据。记录固定引用照片编号，复查照片关联原始记录。道路清理状态保存在该点自身，切换任务不会恢复堵塞。完成三处巡检流程时仍有两处需要后续处理。

可导出包含原始照片、复查照片、处置安排与待办状态的独立 HTML 记录。刷新或重新巡查会开始新一轮；需要保留成果时先导出。

## 教学边界

青溪桥、尺寸、地形和表观异常均为教学设定。通行与影像质量门槛不是现场设备能力、工程验收或结构安全标准。水迹不能直接证明来源，涂层线状异常不能直接证明钢材开裂。独立系绳是本课预设作业条件。

资料入口在页面“操作与依据”中：FHWA高分辨率摄影、TxDOT桥梁检查记录、Boston Dynamics平台环境条件、CMU磁吸爬壁研究。采用记录与能力边界的思路，不移植国外检查等级或处理时限。
