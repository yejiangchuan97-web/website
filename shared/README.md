# 公共资源

[返回任务目录](../README.md)

这里只保存多个任务共用的模型、样式、工具包和跨任务检查，以及原主题的综合说明。日常使用和修改从各任务文件夹开始。

- 机器人构型与运动：驱动、工具和底盘共用的页面框架及综合模型检查。
- [vendor](./vendor/three-r160.min.js)：统一的 Three.js r160，供六轴机械臂、感知与主体结构施工等任务构建使用。
- [robot-arm](./robot-arm/six-axis-arm.js)：全课程统一六轴机械臂（第三章教学六轴臂），含关节角、末端求解与工具挂点；3-1、3-2、3-4、5-2、6-1、6-2、6-3 构建时内联引用，不要在任务里另做机械臂。
- [anatomy](./anatomy/iso-kit.mjs)：统一的 Anatomy 绘图工具、样式和检查模块，供感知、主体结构及装修任务共用。
- 感知与识别：综合入口、说明与旧版综合演示源码。
- 主体结构施工、装饰装修施工：各主题使用说明。
- [认识智能建造](./认识智能建造/README.md)：第一章三份任务导读的共用阅读模板。
- [安全操作与维护](./安全操作与维护/README.md)：第八章四份任务导读的共用模板与构建方式。

共用资源保留原许可证。任务3-3的 Anatomy 与此处版本不同，继续保留在任务内。旧公共库副本已归档到 archive/duplicates/；日常维护只使用 shared/ 中的公共版本。

构建器处理任务专用代码；统一构建收尾时将公共 JavaScript 库改为 shared/vendor/ 引用。离线使用须同时保留公共资源目录。详见[仓库维护说明](../docs/仓库维护说明.md)。
