# 任务3-3重做：两张可以玩的机械实验台

规格：两个独立Hero页面，每页一张可切换机构的实验台；16:9桌面优先，手机模型／操作切换。每次只显示一个机构。浅色默认、深色可切换、本地离线。

## 对象与教学关系

减速器页：输入手轮带动可拆的减速器试验台；学生找固定件、预测并运行一圈、将输出盘停在目标窗口。只讨论齿圈固定、太阳轮输入的行星结构，以及刚轮固定、波发生器输入的谐波结构。

转换页：同一精密送料台换装丝杠、齿轮齿条、曲柄连杆；学生直接操作输入轴，观察滑台怎样移动，选择导程或曲柄半径，完成定位和行程挑战。无电机调参、RV、伺服回路内容。

## 真实关系与设定

- 行星：太阳轮18齿、行星18齿、内齿圈54齿，3个行星，齿圈固定。输入角θ，行星架θ/4，行星绝对自转-θ/2（加安装初相）。中心距36教学毫米，模数2。三行星装配条件(18+54)/3=24。
- 谐波：柔轮200、刚轮202，刚轮固定；波发生器θ，柔轮-θ/100。一输入圈输出反向2齿，即-3.6°。杯体椭圆变形用于结构教学，不模拟弹性应力或接触载荷；不夸大输出转速。
- 丝杠：直线位移=输入圈数×导程，4/8/16 mm可选。有限导轨行程80 mm，限位时输入同步停止。
- 齿轮齿条：节圆半径12 mm，位移=12θ；齿轮24齿，模数1。一圈约75.40 mm。
- 曲柄滑块：连杆长70 mm，曲柄半径15/25/35 mm；x=r cosθ+√(L²-r² sin²θ)，行程2r。模型、读数、目标判定都取同一状态。

依据：Harmonic Drive官网Technology（https://www.harmonicdrive.net/technology）核对柔轮杯、波发生器、固定刚轮、两啮合区及每圈反向两齿；THK滚珠丝杠说明（https://www.thk.com/jp/en/products/ball_screw/）核对旋转／直线转换和导程定义。具体尺寸、练习目标为教学设定。

## 实现与检查

Anatomy负责物件化设计、四层明暗、实物细节、卡片与慢动作；使用其iso-kit生成离线SVG备用插图。主场景使用项目现有Three.js做真三维，深度缓冲处理遮挡，支持环绕、剖开、爆炸、近看。选择这个实现是为了同时保证完整齿轮剖面和可自由观察的三维，不使用Anatomy beta turn对大量非凸啮合齿轮逐面重绘。

SVG备用图单独进行Anatomy几何／线端检查；真三维用齿数、啮合运动关系、连杆长度、行程极值、停机和游戏判定测试，不将这些检查冒称为Anatomy turn审计。

检查覆盖：两主题、五机构；暂停／单步／一圈；目标挑战与重新开始；切换机构归零；限位；爆炸暂停与恢复；键盘；390宽屏；浅／深主题；无WebGL备用；近景、全装与拆开；离线不请求网络。
