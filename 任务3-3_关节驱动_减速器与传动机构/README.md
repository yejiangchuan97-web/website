# 任务3-3 减速器与运动转换

[返回任务总目录](../README.md)

2026-10-22 按任务3-2的蓝白视觉体系优化三维交互实验室，增强行星架输出、行星轮自转／公转与谐波柔轮输出的可见性。打开 HTML 即可离线使用，两个页面顶部可以互相切换。

| 页面 | 机构 | 动手学习 |
| --- | --- | --- |
| [减速器实验室](reducers.html) | 行星减速器、谐波减速器 | 找固定件 → 预测并验证一圈 → 输出定位 |
| [运动转换实验室](conversion.html) | 丝杠螺母、齿轮齿条、曲柄滑块 | 找直线输出 → 调参数做实验 → 滑台定位 |

## 怎么操作

- 拖空白处环绕观察，滚轮缩放；拖动输入手轮直接驱动机构。
- “剖开”移开遮挡部件，“拆开”观察装配层次；拆开时暂停传动。
- 支持播放、正反单步、完整输入一圈、归零、俯视、近看与运动标记开关。
- 右侧输入／输出转盘与三维机构共用角度；拖动“累计输入圈数”可以直接对照传动结果。
- 行星连续输入可选1／4／8圈，谐波可选10／25／100圈。谐波多圈实验默认将整体速度提高到4×，所有构件同比加速，100∶1关系保持不变。
- 系统设置为减少动态效果时不自动播放；单步、圈数拖动和实验按钮以静态位置变化呈现结果。
- 每个机构有三个挑战，完成记录保存在本机浏览器；关卡可以自由选择。
- 空格播放／暂停，左右方向键单步，Home归零，F全屏。手机通过底部切换“观察模型”和“运动与实验”。挑战折叠在侧栏下方。

## 内容关系

行星：18齿太阳轮、18齿行星轮、54齿固定内齿圈，三个行星轮相隔120°。太阳轮输入一圈，行星架与行星轮轴心同向公转90°；行星轮相对机座自转−180°，相对行星架自转−270°。满足齿数关系54=18+2×18及三行星均布装配条件(18+54)/3=24。

谐波：刚轮202齿固定，柔轮200齿输出；波发生器一圈，柔轮反向转3.6°。形变长轴随输入转动，柔轮材料标记及输出法兰随输出转动。杯口按等弧长材料坐标沿等周长椭圆移动，长轴两处啮合中心对固定刚轮无切向滑动；杯壁作几何插值，齿形与弹性接触为教学简化。旁边的形变观察转盘仅将径向形变差放大8倍，并明确标注；三维机构不作该放大。输入25圈输出−90°，输入100圈输出−360°。

运动转换：丝杠可选4／8／16 mm导程；齿轮齿条节圆半径12 mm；曲柄半径可选15／25／35 mm，连杆长70 mm。旋转、直线位移、行程限制与游戏判定共用同一数学模型。

这些页面用于原理教学，不承担载荷、接触应力、寿命或设备选型计算。丝杠页面不模拟滚珠回流，谐波杯体不模拟弹性应力。

- [设计说明](docs/两页实验室设计.md)、[新版检查记录](qa/rebuild/检查记录.md)。
- [第一版归档](历史版本/第一版/README.md)：原方案与旧演示。原配套视频和旧源码保留；原视频对应第一版。

在仓库根目录运行：

```text
node scripts/build.mjs 3-3
node --test 任务3-3_关节驱动_减速器与传动机构/qa/rebuild/model.test.mjs
```

重新生成并审计静态备用插图：`node scripts/build.mjs 3-3 --audit`。此审计只覆盖Anatomy SVG备用图，主体三维由WebGL深度缓冲绘制，另做运动关系和浏览器交互检查。无WebGL时只显示静态分解参考，读数和按钮仍然可用。

## 原理来源与组件

- [KHK 齿轮机构与装配条件](https://khkgears.net/new/gear_knowledge/gear_technical_reference/gear_systems.html)：行星机构齿数关系、行星轮均布与转速关系。

- [THK 滚珠丝杠说明](https://www.thk.com/jp/en/products/ball_screw/)：旋转与直线转换、导程。
- Anatomy：实物实验台设计方法与静态SVG备用图；组件许可见 `assets/anatomy/LICENSE`。
- Three.js：使用仓库现有r160组件，已内嵌到页面，许可证见 `assets/THREE-LICENSE.txt`。
