# 第六章 · 装饰装修施工

[打开章节总览与知识总结](index.html)

沿“工艺体验 → 定位与执行 → 反馈观察 → 复核与交接”组织四个交互课堂。入口延续第三至五章的蓝白三维展台，支持选课、环绕观察、巡展、暂停、学习导览与章节总结。

| 任务 | 主要操作 | 入口 |
|---|---|---|
| 6-1 砌筑工艺与机器人 | 转砖、试排、错缝，人工难点与机器人基准反馈 | [砌筑课堂](../任务6-1_砌筑工程_人工工艺_砂浆机械与机器人进场/index.html) |
| 6-2 地砖铺贴实训 | 低位试提、视觉纠偏、压实与高差复核 | [铺贴实训](../任务6-2_地砖铺贴_工艺准备与铺贴机器人作业/index.html) |
| 6-3 腻子打磨实训 | 接触力与退让、磨料与表面、控尘、验收与养护 | [打磨工坊](../任务6-3_腻子打磨_作业面检查_恒力执行与质量验收/index.html) |
| 6-4 室内喷涂工坊 | 规划、试喷、正式喷涂、巡检返修与记录交付 | [喷涂工坊](../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/index.html) |

各课堂每次打开默认深色，顶部可切换任务、主题或返回章节总览。原有交互与数据模型保留，任务独立运行，不自动跨页传递记录。页面中的工艺参数与质量判断仍按各任务分别说明。

在仓库根目录执行 `node scripts/build.mjs 6` 构建入口与全部页面，执行 `python scripts/package-chapter6.py --output <输出目录>` 生成独立站点与 ZIP。各 HTML 含本地运行所需脚本与素材；原有外部资料链接需联网。

公共导航位于 `公共资源/装饰装修施工/chapter-layout.*`。入口基础 CSS 复用第三章，独立样式、内容与四组展品位于本章 `src/`。`scripts/check-chapter6.cjs` 验证入口导航、默认主题、主要工作流程与布局，需要 Playwright 和 Chromium 浏览器。
