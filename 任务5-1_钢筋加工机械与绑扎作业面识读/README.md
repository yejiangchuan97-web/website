# 任务5-1｜钢筋工地开工挑战

[打开互动页面](index.html) · [返回任务目录](../README.md)

一个可离线打开的课堂导入游戏。桌面主界面为 16:9；手机竖屏按内容排列。页面统一采用微软雅黑字体栈，沿用任务3-2的浅蓝底、深蓝文字和主蓝色，橙、青、绿、红分别承担机械识别与区域提示。

## 三关教学主线

| 环节 | 学生动作 | 学到什么 |
| --- | --- | --- |
| 加工接力 | 将材料拖到机械，移动切断挡块至 2400 mm，将弯曲转角调到 90°，启动并观察三台机构 | 调直改变平直度，切断改变长度，弯曲改变形状；本例采用先切后弯 |
| 楼面巡查 | 找到梁板边线、柱边、洞口、交点、堆料和人员通道；搬走堆料、清走料箱、放置护栏；操作四项检查工具 | 识读现场边界、通路与作业条件，观察质量检查点 |
| 分区交接 | 在规则大面、柱边、洞口放置彩色区标，保存交接记录 | 区分机器人候选区、人工处理区与禁止进入区 |

所有拖放都有点击操作的替代方式，支持 Tab / Enter。加工过程中可暂停；减少动态效果时直接呈现结果。三维不可用时自动启用互动俯视图，三关仍可完成。

检查台保留教材要求的四项内容，使用具体工具动作：
- 点击圈出缺少绑丝的交点。
- 拉出卷尺，对照本例的 400 mm 设计值与 480 mm 实测示意。
- 切开局部剖面，补上垫块，理解从模板面至最外层钢筋外缘的 42 mm 示意净距。
- 给疑似松扣留下“待人工检查”标记；不凭外观宣布牢固或合格。

## 内容依据

依据[来源11：主体结构施工协同](../来源/11_5.主体结构施工协同.txt)中任务5-1的四项任务：加工工序、六处现场位置、四项质量检查点、人机作业分区。机器人开机、低速验证、送丝扭结与连续绑扎操作留到任务5-2。

原来的右侧选择题和下方“不同问题用不同方法复核”题组已移除。“半成品”在主流程中改为“已调直钢筋”“定尺钢筋段”“加工好的弯折钢筋”，让材料名称与当前形态一致。

## 源码与构建

```powershell
node "任务5-1_钢筋加工机械与绑扎作业面识读/src/build.mjs"
node "任务5-1_钢筋加工机械与绑扎作业面识读/src/build.mjs" --audit
```

构建将本地 Three.js、页面、样式、场景、交互与 Anatomy 检查台全部内联到 index.html，不需联网或启动服务。

- src/page.html、style.css、app.js：16:9 界面与游戏状态。
- src/scene.js：三维机械、现场搬运、护栏与区域标记。
- src/model.mjs：原有机械运动与几何模型。
- src/inspection.js：Anatomy 生成的钢筋检查台与工具交互。
- qa/build-inspection-fixture.mjs：检查台可复现生成及静态几何审计。依赖已安装的 anatomy 技能，可用 ANATOMY_SKILL_DIR 指定位置。
- qa/game-actions*.json：Anatomy drive 的桌面、手机及无 WebGL 操作回归。
- qa/2026-10-22-游戏改版检查.md：此次改版的检查范围与结果。

build --audit 运行原有教学模型检查，不等同于整个三维场景的 Anatomy 几何审计。

## 教学边界

订单、尺度、偏差与布局均为教学设定，不是通用施工阈值；具体设备也可能采用先弯后切。本页交接的是识读结果与候选作业区，不能替代现场安全检查、机器人进场核实或施工验收。四项检查采用独立局部样板，不暗示对整片楼面完成了真实检测。
