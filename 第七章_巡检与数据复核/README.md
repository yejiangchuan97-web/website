# 第七章 · 巡检与数据复核

[打开章节总览与知识总结](index.html)

沿“明确对象 → 到位取证 → 对照复核 → 记录与跟踪”组织两个交互课堂。入口延续前面章节的蓝白三维展台，支持选课、环绕、巡展、暂停、学习导览与章节总结。

| 任务 | 主要内容 | 入口 |
|---|---|---|
| 7-1 桥梁巡检机器人 | 轮式、四足与磁吸爬壁平台，到达条件、真实取景、原始照片、同点复查与后续事项 | [桥梁巡检](../任务7-1_巡检机器人_轮式_四足与爬壁/index.html) |
| 7-2 无人机巡检与影像复核 | 六个点位、采集质量、误报漏报、补拍与重审、版本记录与导出 | [无人机实训](../任务7-2_无人机巡检_病害检测与数据复核/index.html) |

课堂每次打开默认深色，可在顶部切换主题、任务或返回总览。7-1 原有机器人、部件展示与证据流程保留；7-2 恢复浏览器已保存的任务进度，但每次进入均重置为深色显示。任务之间不自动交换照片和记录。

桥梁照片由本课三维现场取景生成。无人机影像、候选框和分数为合成教学样例，页面不运行病害检测模型。既有各任务的教学范围和质量判断说明保持在相应课堂内。

运行 `node scripts/build.mjs 7` 构建入口与全部课堂；运行 `python scripts/package-chapter7.py --output <输出目录>` 生成独立站点与 ZIP。脚本与素材内嵌，外部资料链接需联网。

导航源码位于 `公共资源/巡检与数据复核/chapter-layout.*`，入口源码位于本章 `src/`。基础 CSS 复用第三章；两组展品只用于章节导览。`scripts/check-chapter7.cjs` 验证导航、默认主题、部件展示、取证复查、版本复核与离线布局，需要 Playwright 和 Chromium 浏览器。
