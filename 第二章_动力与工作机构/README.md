# 第二章 · 动力与工作机构

[打开第二章入口](index.html)

入口沿用第三章的蓝白配色、1600 × 900 等比例画布、可环绕三维展台、逐站巡展、学习导览与任务卡。三项任务按“产生动力 → 传递动力 → 完成动作”组织为五个实验：

| 任务 | 实验入口 | 观察重点 |
| --- | --- | --- |
| 2-1 动力装置的基本原理 | [直流电机](../任务2-1_动力装置的基本原理/index.html) · [柴油机](../任务2-1_动力装置的基本原理/diesel.html) | 电流、磁场、转矩；四冲程与多缸协同 |
| 2-2 动力的传递与变换 | [动力传动](../任务2-2_动力的传递与变换/index.html) | 齿轮、带、链；液压与气压推动 |
| 2-3 工作机构与施工动作 | [工作机构](../任务2-3_工作机构与施工动作/index.html) · [四杆扩展](../任务2-3_工作机构与施工动作/fourbar.html) | 动臂、丝杠、偏心振动；轨迹、传动角与夹持 |

五个实验顶部共用本章导航，可切换实验、返回章节总览或课程总目录。每次进入实验均默认深色，即使上次选择过浅色，也不会改变下次的默认模式；柴油机、动力传动和两种工作机构仍可在本次浏览时手动切换主题。入口保持蓝白展台，入口及全部实验的字体均已放大。

电机页常显“观察电机、理解原理、机器人应用”三个入口，组装、排故与模型说明从“进阶学习”进入。默认显示磁极、青色电流粒子和橙色受力箭头及光点，部件名称仍收起；电流与受力可用模型上方的开关统一关闭。常用控件保留电压、负载、极性、暂停与复位，剖切程度、详细数据、标注设置及示教角度收在“更多设置与详细数据”中。柴油机内容分为结构与运行、多缸协同、四冲程观察三个活动，工作机构的教学要点可展开阅读。原模型、计算、装配和交互逻辑继续保留。

## 构建与维护

在仓库根目录执行 `node scripts/build.mjs 2` 更新入口与全部实验；也可分别使用 `2-entry`、`2-1`、`2-2`、`2-3`。更新任务清单后执行 `python scripts/build-course-cover.py` 同步课程总目录。

- `src/page.html`、`app.js`、`scene.js`、`style.css`：入口结构、选课、三维展品和本章样式；基础版式在构建时复用第三章样式，输出 HTML 可独立加载。
- `../公共资源/动力与工作机构/`：实验导航、配色与构建整合函数。
- `../任务2-1_动力装置的基本原理/build.cjs`：生成柴油机单文件页；电机的简洁版布局由 `assets/simple-layout.js` 与 `simple-layout.css` 提供。
- 任务 2-2、2-3 的原构建脚本同时写入共用导航；2-3 新增根目录入口，原 `dist/` 入口继续可用。

执行 `python scripts/package-chapter2.py` 打包当前页面。输出的 `site/index.html` 与 `site/lessons/` 五个单文件实验可直接离线打开或上传静态托管，不需要联网加载脚本、字体和模型。包内采用英文路径；原仓库版本继续保留课程总目录及第三章入口。

入口展品是对应原理的教学示意；详细机构与计算仍以各实验原有说明为准。

## 浏览器检查

安装有 Playwright 与 Chromium 的环境中运行 `node scripts/check-chapter2.cjs`；使用系统 Edge 时设置 `CHAPTER2_BROWSER=msedge`。检查章入口交互、五个实验导航与主要操作、四种窗口尺寸、离线资源和 WebGL 降级。打包后可用 `--site 输出目录/site --packaged` 检查实际交付包。
