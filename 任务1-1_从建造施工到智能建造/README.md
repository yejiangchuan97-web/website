## 主网页概念与大致效果

页面中央是可剖开的教学楼，底部有“基础—主体—装修—运维”阶段按钮。点击楼内热点即可进入钢筋网Rebar-A、楼面Floor-A、墙面Wall-A、外立面Facade-A。右侧并排显示“人工或机械作业”“引入机器人后”，学生可以自由选择场景，拖动比较分隔线；没有必须完成的统一步骤。

场景中的人、设备、物料和危险区域使用不同轮廓。动画只表现工作动作、人员位置和数据用途，不用夸张效率条把机器人默认呈现为最优方案。首屏提供“先看外墙喷涂”的独立示例。

## 值得做的交互点

1. **痛点不是单选标签。** 学生点选Facade-A的吊篮人员、喷雾和重复往返动作，画面分别突出高处坠落暴露、漆雾暴露、重复动作；“危、繁、脏、重”可多选。选中某痛点后只显示对应证据，帮助学生把判断落到具体动作，允许同一作业有多种痛点。
2. **替代动作与保留职责。** 将“自动往复喷涂”“供料”“作业面确认”“异常恢复”“质量复核”拖到设备或人员旁，动画改变分工：机器人承担规则墙面的重复运动，人员仍确认洞口、材料与异常处理。没有依据的“全部交给机器人”会出现条件缺口提示，而不是简单扣分。
3. **技术有具体作用。** 在Wall-A上点“洞口尺寸”“墙距变化”“疑似漏喷”，把BIM、距离传感、视觉识别和机器人执行卡连接到相应问题；画面显示模型轮廓、实时距离线、疑似缺陷框与喷嘴路径。每条连接标明数据或动作的用途，理解技术组合并非越多越好。
4. **施工阶段与岗位变化。** 切到主体阶段出现Rebar-A和混凝土作业；切到运维阶段出现Route-A巡检路线。点击“操作员”“质量员”“维护人员”，用一段十秒动画展示其确认或处理事项，理解岗位职责随设备应用变化，而不是背新岗位名称。
5. **条件改变后的取舍。** 打开“洞口密集”“材料未就绪”“通道被占”情境卡，学生选择机械、机器人或人机协同，画面保留现场限制与未解决问题。支持多个有依据的方案，避免把自动化程度当作唯一答案。

## 重点演示与实施顺序

先做一组Wall-A人工与程序喷涂比较：规则墙面能自动往复，窗洞需要避让，墙距异常导致暂停，人工确认后恢复。再补Rebar-A绑扎与Floor-A打磨两组热点，支持痛点多选和分工拖卡。扩展才制作外立面场景、跨阶段岗位卡和教师自行添加情境的功能。

可参照原文所列施工视频的动作片段，素材发布授权需另行核对。无需要求每个学生下载记录；教师可直接投屏让全班解释一种选择。

## 表现边界
