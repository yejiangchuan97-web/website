# 4-1 新版独立浏览器验收计划

此目录的脚本只读取已生成的 `4-1.html`，通过浏览器操作、截图、下载测试文件及生成报告，不修改教学源代码、参考页、4-2 或 4-3。

运行：`node 04_感知与识别/教学演示/qa/redesign/verify-v2.mjs`。可用 `--only=04,09` 选择测试编号，或 `--url=http://127.0.0.1:4174/4-1.html` 指定地址。默认使用本机 Edge 和本地 file 页面，验证离线能力。输出放在 `v2-results/`。

1. 真三维与构图：正常环境出现真实 canvas，降级图隐藏；1440 桌面画布至少 800px 宽、500px 高，无横向溢出，保存模型统计。
2. 主题与视角：蓝白/深色、透视/正视/侧视/俯视均可切换，按压状态准确，重置有效。
3. 人机操作：观察与操作模式、拖动倾角、键盘方向键、四个部件详情、舱盖与坐标开关。
4. 静止重力：0°、30°、−30°、50°的三轴值符合姿态，合量9.81m/s²；去重力归零；挑战先预测、必须有证据。
5. 回转：4s与1s都到90°，中点角速度峰值之比4；记录慢快两次；挑战验证总角度和峰值不是同一概念。
6. 振动：可连续三次采集，统一窗口；松动、激振频率和轻敲可操作；不把单个峰值直接当作碰撞证明。
7. 位移：A/B独立标尺相距0.50m；无偏置积分一致；0.01m/s²偏置经过10秒累计0.50m误差。
8. 实验单：证据数量、姓名、JSON/CSV导出，数据非空且可解析。
9. 手机CSV：分号、毫秒、g单位，显式映射后转换；缺失y轴不补0、不允许保存；空窗口不保存；有效窗口保留文件来源；导入曲线不得驱动三维姿态。
10. 四个实验只显示当前实验的控件，避免参考手机页3036px长表单；导入区默认收起。
11. 正常环境无页面异常、GL错误、控制台错误、外部网络资源请求。
12. 390px触摸布局无横向溢出，三维模型仍有足够空间，切换与记录可用。
13. Reduced motion不自动推进，手动定位仍能到90°。
14. 禁用WebGL时显示降级内容、计算和记录仍可用、无未捕获异常。

## 三维与模型交叉验证契约

页面提供 `window.__SENSE__.snapshot()`、`setState(patch)`、`sceneStats()`、`records`。浏览器脚本优先验证用户可见读数，API仅用于交叉检查。

为独立验证三维姿态与重力值一致，建议 `sceneStats()` 附加 `robotWorldAxes: {x:[x,y,z],y:[x,y,z],z:[x,y,z]}`（机体三条轴在世界坐标的单位向量）、`worldGravity:[0,0,-1]`。将每条机体轴与世界向上向量点乘再乘9.81，应等于同一时刻显示的本体比力分量。该校验需在场景实现后依真实字段适配。

## 截图人工检查

每张输出PNG都需实际打开：桌面蓝白/深色、倾斜30°、回转90°、振动、位置、CSV实验单、390完整页与首屏、Reduced motion、WebGL降级。检查模型是否清楚、机件是否悬空或相交、轴是否跟随机体、文字是否被遮挡、控件是否可触达、手机表单是否过长。再对核心部件与连接处作4倍近看。自动通过不能替代图像检查。
