# 课程总封面

课程名称：智能建筑机械与机器人。设计采用浅蓝背景、深蓝文字与统一的三维实训展台，避免以课程截图拼贴作为总入口。

## 导航

- 课程全景：八个章节的主题模型，点击标签或章节菜单展开任务。
- 第3章：构型机构、机械臂、行星传动示意、末端夹具和移动底盘五组模型。
- 任务3-1、3-2、3-4、3-5可由模型标签或任务菜单直接进入；3-3在任务菜单中列出减速器、运动转换两个入口。
- 全部任务：完整27项任务目录，支持名称与编号搜索。未制作或未打包的任务标注状态，不生成不可用链接。
- 页面使用原生链接与浏览器历史记录；目录用原生对话框；窄屏时章节横向排列，任务列表位于模型下方。

## 构建与发布

`python scripts/build-course-cover.py --package`

根目录 `index.html` 使用当前仓库已存在的课程入口；`.local/course-cover-chapter3/site/index.html` 是独立示例包入口，只接入第3章，其余章节完整列出任务并标注“后续接入”。ZIP根目录为网站入口，解压后可直接打开，不需要联网加载第三方资源。

`data.js` 由 `任务清单.json` 生成。课程名称与说明在构建脚本中配置；不必逐项修改菜单链接。

三维模型为课程封面专用的教学主题模型，并非设备数字孪生或原课模型的原样复刻。模型构造与轻量运动在 `scene.js` 中；运动可暂停，并遵循系统减少动画设置。WebGL不可用时，章节菜单与课程入口仍可使用。

本次验证覆盖：第3章六页浏览器导航和返回链接、27项目录、TCP搜索、双实验室选择、暂停状态、390px页面宽度。封面模型已通过画布导出检查；整体布局预览通过浏览器打印输出检查，普通截图接口超时，未将其作为页面故障。未重复验证每个原课程的全部教学交互。
