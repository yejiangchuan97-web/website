MODEL NOTES

看得见运动，也读得懂原理。

三维教学模型。动画、流量、体积和读数由同一个物理状态驱动；各模型在对应假设内满足传动关系与守恒关系。

01 / 齿轮、带与链

直齿轮采用 20° 压力角渐开线、相同模数及标准中心距；外啮合两轮反向，n₂ = −n₁ z₁/z₂。开式平带依靠摩擦，两轮同向；设定无打滑，n₁d₁ = n₂d₂。滚子链依靠滚子与链齿的几何啮合，两轮同向，平均速比等于齿数比。链的显示采用节线近似，忽略多边形效应引起的瞬时速度波动；带的弹性、打滑及张紧动态未模拟。

机械传动的转矩按恒定效率估算：齿轮 97%、带 95%、链 98%。输出转矩 T₂ = η T₁ |n₁/n₂|，输入功率 P = T₁ω₁。细虚线为节圆 / 节线，不是实体零件。

02 / 双作用液压缸

A = πD²/4，B = π(D²−d²)/4。伸出 v = Q/A，缩回 |v| = Q/B。液压油按不可压缩、无泄漏处理，采用准静态模型：入口压力由阻力、100 N 摩擦力及 0.1 MPa 回油背压共同决定。压力设置是溢流上限，不是固定工作压力。负载超限或到达终点时，缸口流量为零，泵流量经溢流支路回油；中位为封闭中位，泵仍经溢流阀回油。显示“进油量”为累计进入缸腔的油量，不包括溢流量。

03 / 双作用气缸

采用等温集中参数双腔模型：p绝对V = mRT；阀口采用含临界阻塞的可压缩流量关系。按两腔压差、12 kg 等效质量、25 N 摩擦及 300 N·s/m 阻尼积分活塞运动，展示充气建压、压缩、排气与负载停滞。负载为双向运动阻力。封闭中位会保留空气，活塞可能因压差和惯性继续微动，不能视为机械锁。端点为刚性挡块。未计温升、泄漏、软管容积和行程缓冲。

所有压力读数均为表压。气量统一折算至 20°C、101.325 kPa 绝压，以 NL / NL·min⁻¹ 显示（本页约定参考状态，非 0°C 标准状态）；气体实际腔容积另以 mL 显示。气动流量旋钮为 0.7 MPa 绝压上游、临界流动下的额定供气能力，实际流量随压差变化。A/B 均含 5 mm 等效死容积。

操作

1 / 2 / 3 切换装置；空格播放或暂停；R 重置当前实验；Home 复位视角。拖动旋转，滚轮或双指捏合缩放，Shift 拖动平移。单步始终前进 0.1 秒模拟时间。切换装置保留各自状态；更换几何尺寸或传动方式会重置当前实验，避免状态突变。桌面固定视窗，小屏仅控制区内部滚动。

零件观察与学生任务

点击组件名称会独立展示对应零件，并暂停整机；可拖动观察各个方向，开启自动旋转，或从零件说明中切换其他组件。Esc 或“返回整体”恢复整机。机械传动可切换 1、2 号轴为输入，盘车按钮使输入轴正向转过 15°。

“学习任务”包含轴系装配、输入轴对换、液压接管和气缸加载四项练习。装配题以预装轴承座、轴、键、齿轮、轴环的教学顺序进行，齿轮配对检查模数与压力角；结果只验证本页的连接、顺序与运动关系，不代替实际装配公差与强度检验。模型外观采用教学比例。通过记录保存在本机，可导出文本实验记录。
