# 第五章 · 主体结构施工协同

[打开章节总结入口](index.html)

沿“加工准备 → 绑扎与复核 → 工序接续”组织本章学习。入口沿用第三、四章的蓝白三维展台，提供选课、巡展、暂停、环绕观察、学习导览与章节总结。

| 任务 | 内容 | 入口类型 |
|---|---|---|
| 5-1 钢筋加工与作业面识读 | 加工接力、楼面巡查、检查工具、分区交接 | [交互课堂](../任务5-1_钢筋加工机械与绑扎作业面识读/index.html) |
| 5-2 钢筋绑扎与人工复核 | 对准与绑扎、人工检查、正常供丝与卡丝观察 | [交互课堂](../任务5-2_钢筋绑扎机器人操作与人工复核/index.html) |
| 5-3 混凝土施工工序导读 | 六道工序、设备与人工分工、标高反馈 | [工序导读](../任务5-3_混凝土泵送布料与整平抹光机器人/index.html) |

三个页面每次打开均默认深色，可在顶部切换主题和任务、返回本章总览。5-1、5-2 原有交互保留，页面之间不自动传递记录。5-3 依据现有教学方案整理为导读，尚无混凝土交互仿真；历史演示已迁移到任务6-3，不作为本章入口。

在仓库根目录运行 `node scripts/build.mjs 5` 构建本章入口与所有页面；运行 `python scripts/package-chapter5.py --output <输出目录>` 生成独立站点与 ZIP。各 HTML 内嵌本地脚本和素材，可双击离线打开。

导航源码位于 `公共资源/主体结构施工/chapter-layout.*`。入口基础 CSS 复用第三章，独立样式与三维展品在本章 `src/`。维护后运行 `scripts/check-chapter5.cjs` 核对导航、默认主题与主要交互；该脚本需要 Playwright 与 Chromium 浏览器。
