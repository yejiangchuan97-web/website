# 教学模型与边界

## 电机平均稳态模型

| 参数 | 值 |
| --- | --- |
| 电枢电阻 R | 1.20 Ω |
| 转矩常数 Kt | 0.060 N·m/A |
| 反电动势常数 Ke | 0.060 V·s/rad |
| 粘性阻尼 b | 0.00012 N·m·s/rad |
| 示教电压幅值 U | 0–24 V |

参数为教学假设，不对应具体产品。Kt 与 Ke 在 SI 单位下数值相等。

```text
U = RI + E
E = Ke·ω
Te = Kt·I = T轴 + b·ω
ω = max(0, (Kt·U/R − TL) / (Kt·Ke/R + b))
n = 60·ω/(2π)
P轴 = T轴·ω
P入 = UI = P轴 + I²R + b·ω²
```

未堵转时轴转矩等于阻性负载。超出启动能力时速度归零，电机转矩受堵转能力约束。反接比较两个稳态；数值卡主要显示幅值，电流与运动方向另外标识。零电压按无外力驱动静止处理。

例如 U = 24 V、TL = 0.42 N·m 时：ω = 250 rad/s，n ≈ 2387.324 rpm，I = 7.5 A，P轴 = 105 W，P入 = 180 W。

## 电流与磁场

构造与换向图放大一个线圈和二片分裂环。稳态读数使用多线圈平均特性，不能据此推断单线圈瞬时速度。

二维原理图从输出轴端看：右为 +x，上为 +y，出屏为 +z。磁场从 N 指向 S，沿 +x。传统电流出屏时受力向上，入屏时向下；一对力形成转矩。线圈在零转矩位置理想换向。剖切只改变可见性，计算仍使用完整磁路。

## 故障挑战

- 接触不良：串联额外接触电阻 Rc，使用 U = I(R + Rc) + Ke·ω，额外损耗为 I²Rc。
- 开路：I = 0，电机停止。
- 过载：负载超过启动能力，进入静态堵转约束。

挑战使用 12 V，恢复后的示教负载为 0.18 N·m；接触不良示例 Rc = 6 Ω。修复验证同时检查根因是否排除和电机是否恢复转动。

## 减速传动与机器人

```text
g = |n输入/n输出|
T输出 = η·g·T轴
P输出 = η·P轴
F等效 = T输出/等效力臂
```

应用场景使用两级外啮合复合齿轮，分级减速比 a×b = g。中间轴与输入轴反向；两次外啮合后，输出与输入同向。在第二级加入惰轮只改变外啮合次数和输出方向，不改变总减速比幅值；效率由效率控件统一指定，不另行叠加每个惰轮的损失。齿形用于传动示意，未进行接触应力、齿形修正或强度设计。

机械臂只驱动肩关节；上臂、肘部、前臂、腕部和夹爪按串联运动学变换。上臂长 0.43 m，前臂长 0.37 m，肘部与腕部相对角固定。肩关节范围 20°–105°，到达软限位后驱动电压归零，可反向返回。巡检定位模式在 30° 与 85° 之间往返，端点先断电停留 0.7 秒（演示时间），再交换驱动极性返回。单次驱动在 20°–105° 软限位停止。保持姿态按制动机构示意处理；负载采用设定的等效阻性负载，未按姿态计算重力矩与伺服控制过程。

应用慢放对所有轴和机构使用同一演示时钟；显示的速度与功率读数仍为真实时间下的稳态计算值。暂停冻结演示时间，保留工作点读数。断电在此稳态模型中立即停止，不计算惯性滑行。

## 肩关节内置电机与功率链

机械臂为本版唯一的机器人应用。电机电枢与一级小齿轮固定在同一输入轴上，一级大齿轮和二级小齿轮共用中间复合轴；输出大齿轮、关节法兰与上臂刚性相连。N/S 表示固定磁极，A/B 表示电源端子；交换 A/B 极性不会交换磁体 N/S。局部绕组和齿形均为教学简化，不用于制造。

默认减速比 g = 80 = 8×10、总效率 ηg = 0.85；每级效率取 √ηg 作为损耗分配假设。中间轴转矩 = T轴·8·√ηg，中间轴功率 = P轴·√ηg；第二级后输出转矩 = T轴·80·ηg，输出功率 = P轴·ηg。惰轮不单独扣减效率。

在 24 V、0.42 N·m 的工作点下：输出转速约 29.842 rpm，肩关节角速度幅值约 179.049 °/s，输出转矩 28.56 N·m，输出功率 89.25 W。电源 180.00 W = 电机损耗 75.00 W + 减速器损耗 15.75 W + 关节输出 89.25 W。界面中的能量等式按两位小数展示，轴速表作适当舍入。

轴的有符号角度为各轴统一约定，肩关节姿态角 q 从水平向上计，dq/dt = −ω输出，因此界面中的关节角速度可带负号。末端位置来自同一组关节变换，而不是独立动画。

## N/S 标识、电流粒子和部件观察

N/S 是固定永磁体的北极和南极；A/B 是电机电源端子。电源反接只交换 A/B 极性及传统电流方向，不交换 N/S。三维模型中的标记锚定在相应磁体上；放大单个磁体时可暂隐其他组件，完整磁路仍用于数值计算。

发光粒子只说明传统电流（正电荷运动约定）的方向，不表示电子轨迹，也不代表真实电荷数量或测得的漂移速度。机械换向会交换等效线圈导体中的方向；粒子按照这一方向变化。堵转时转子静止但仍有电流，粒子因此可以继续流动；主动断电或开路时隐藏粒子。暂停冻结示意动画，减少动态效果模式使用静止粒子和方向箭头。

点击部件名称仅改变相机、显示范围或组件可见性，不改变电压、负载、减速比和机械臂姿态。机械臂关节和末端的放大镜头跟随同一组运动学变换。


## 三维磁场、导线受力与转矩

三维构造模型以输出轴为 +X，固定 N 极在 −Y、S 极在 +Y，因此气隙磁场 B 沿 +Y。肩关节电机的轴沿 Y，N 在 +X、S 在 −X，因此 B 沿 −X。两种视图使用各自的三维坐标，同样遵守右手叉乘。

每根等效有效导线满足 F = Iℓ × B，一对相反受力的合转矩为 τ = r₁ × F₁ + r₂ × F₂。箭头锚定在两根导线的中部；反接时 I、F 与 τ 反向，永磁体的 B 保持不变。换向器按线圈位置每半周交换导线中的电流方向，使通电后的转矩保持指定旋转方向。理想换向位置的等效单线圈电流、受力与转矩箭头暂隐；断电时仍显示固定永磁体磁场。

矢量长度和磁场均匀分布是方向教学示意，不表示真实的磁通密度、导线受力或电荷速度。单线圈归一化转矩因子为 ±|cosθ|，上方速度、电流和转矩读数仍采用多线圈平均稳态模型，不能把单线圈零转矩位置等同于整台电机停止。暂停仅冻结演示，不表示断电。
