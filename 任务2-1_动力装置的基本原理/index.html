数值来自同一个平均模型

本页采用永磁有刷直流电机的稳态方程。参数为教学假设，不对应某一具体产品。电压幅值 0–24 V；电阻 R = 1.20 Ω；Kt = 0.060 N·m/A；Ke = 0.060 V·s/rad；粘性阻尼 b = 0.00012 N·m·s/rad。Kt 与 Ke 在 SI 单位下取相同数值。

U = RI + E,　E = Keω
Tₑ = KtI = T轴 + bω
ω = max[0, (KtU/R − Tᴸ)/(KtKe/R + b)]
P入 = UI = T轴ω + I²R + bω²

负载是随转向改变方向的阻性负载，阻碍转动。未达到堵转时 T轴 = Tᴸ；超出能力时转子停住，可传递转矩上限为 KtU/R，超出部分由约束承受，不显示成虚假的电机输出。0 V 按无外力驱动静止处理。

曲线和读数使用幅值；反接时电流、角速度和转矩的有符号值同时反向，所以电动工况功率仍非负。这里切换的是两个稳态，未仿真反接制动、再生、电感与加速瞬态，也未建立温升模型。大电流和堵转状态仅用于教学，不代表可连续运行。

看懂剖切与换向

三维结构放大一个线圈与二片分裂环，帮助识别部件。数值采用多线圈平均特性；二者不能用来推断单线圈的瞬时速度。剖切同时移除近侧部分磁体以显露绕组，仅改变可见性，不改变计算中的完整磁路。

二维图从输出轴端看，向右为 +x、向上为 +y、出屏为 +z。磁场沿 +x，从 N 指向 S。出屏的正电流在磁场中受力向上，入屏时受力向下。正向时右侧导线出屏、左侧入屏，形成逆时针转矩。

示教角 θ 从向右方向逆时针计。单线圈转矩幅值与 |cos θ| 成正比，90°、270°为零转矩位置；理想换向在此交换线圈电流，电刷处接触间隙被简化。暂停仅冻结动画，步进和角度条用于观察，稳态数据保持。

音效使用本地 Web Audio 合成，音高与转速联动，反映运行趋势；不模拟真实声压、频谱或故障特征。默认静音，点击开启后播放。

故障模型

电刷接触不良用额外串联接触电阻 Rc 示教：U = I(R + Rc) + Keω，接触损耗为 I²Rc。开路时 I = 0；过载时按静态堵转约束处理。故障挑战采用 12 V，正常示教负载为 0.18 N·m；Rc = 6 Ω 只是本题故障参数，不是产品测量值。修复前后比较稳态，不模拟电弧、温升或机械加减速过程。
