# 3-5 三维重做

范围：只重做 3-5，保留 3-3、3-4 当前交付。继续使用离线内嵌 Three.js；单一三维机构随构型切换，不同时铺开多台机器。保持 16:9 单屏布局。

核心：真实轮轴、滚子、支承、履带闭合路径、足式关节与空间障碍组成一台可观察和操纵的机器人。机构视角跟随底盘，场地视角观察路线，俯视用于验证几何；所有视角共用同一世界坐标与运动状态。

零件：台面、底板、四支脚、角螺栓、标尺条、地面分格、围边；底盘纵梁、横梁、连接板、电池、压带、驱动器、散热片、外盖、检修盖、盖板紧固件、保险杠、急停按钮、支柱、扫描器、灯、牵引环；电机、减速箱、轴承座、轴、轮毂、法兰、紧固圈、轮胎、胎纹、轮辐、随动轮支架、转向座；麦轮侧板、十二斜滚子、滚子轴、端帽；履带驱动轮、导向轮、支重轮、回程托轮、履带板、销轴、接地色标；足式髋座、髋电机、上腿、膝关节、下腿、球形足垫；轨道、轨枕、安装座、轮缘；磁极块、密封圈、负压腔、防坠缆、壁面支架；材料箱板材、围带、托盘、立柱、隔墙、停靠标记。通过真实尺寸和连接关系增加细节。

模型真值：轮速、车体运动、轮轴角均共用同一模型；Ackermann 前后轴参考点统一为车体中心；四足使用等长刚杆的三维逆解，区分支撑和摆动；履带板沿封闭路径移动，下侧为接地段。地面场景为刚性水平地面，不把粗糙度卡片描述成真实越障或动力学计算。

空间反馈：箱体、柱体与墙体具有高度；地面完整占用轮廓与当前几何干涉使用相同尺寸。窄转向区以实体围挡和半透明中间轮廓展示；换相机不改变车辆世界朝向。
