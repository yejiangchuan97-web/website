# 任务 3-5：机构观察与驾驶闯关

## 范围与概念

Anatomy Hero：单台可切换构型的三维教学底盘，复用当前 Three.js 实体模型与深度缓冲。每次只展示一台主体；不另建多车辆系统。模型运动解释机构：轮速差改变转向，45° 滚子组合允许横移，转向节改变轮轴方向后车辆沿圆弧移动。行走方式保留履带、四足、轨道。爬壁内容退出本任务页面。

制作顺序：运动学与通关规则 → 零件清单 → 三维场景 → 操作面板 → 实际驾驶、明暗主题、390px 与局部细节检查。此页使用原有 WebGL 实体渲染器；Anatomy 的 SVG recorder / turn 审计不适用于这套网格，不能以空检查冒充通过。以运动学测试、完整车身碰撞、轮轴/足端检查及实际浏览器视图验证。

## 零件清单（机构主体，按装配分组）

- 承载：左右纵梁、前横梁、中横梁、后横梁、底板、前保险杠、后保险杠、左右端盖、前传感器支架两件。
- 外壳：可移除上罩、顶盖、检修盖、四个顶盖紧固件、两侧散热板、18 个闭合散热槽、铭牌。
- 驱动：两/四个电机罐体、减速箱、输出轴、法兰、安装座、每台电机四个紧固件。
- 供电：电池盒、两条压带、两个端子、散热器、驱动器、接线座、三个接线端口。
- 车轮：轮胎/滚子、轮毂、两侧轮缘、六根辐条、轴帽、六个轮毂螺钉；麦克纳姆每轮十二个 45° 鼓形滚子、滚子轴及轴端支承。
- 差速随动：两个回转座、四片叉臂、两个随动轮、两根轮轴。
- 转向：左右转向座、两根主销、左右转向节、前轴支座；内外轮使用各自转角。
- 观察：前后定位基准、急停按钮底座与按钮、扫描器立柱、扫描器外壳与观察窗。
- 行走方式：履带驱动轮、导向轮、支重轮、托轮、96 块循环履带板及销；四足髋关节、膝关节、八根定长连杆、四个足垫；轨道踏面轮、轮缘、轨头、轨腰、轨底、轨枕及扣件。

零件有实体厚度、倒角、接触支撑和真实前后遮挡。封闭通风槽、轮毂紧固件、轮缘和滚子轴作为特写检查重点。地板和环境低对比，蓝色主体，正在讲解的动作使用单一青绿色提示；目标和碰撞的颜色承担状态意义。

## 基础关卡的教学与判定

1. 双轮差速：通过检查点，到宽转身区原地转向后进入纵向停靠区。理解零转弯半径不等于车身没有尺寸。
2. 麦克纳姆：在侧向通道中保持车头方向横移。记录全程最大朝向偏差，超过 10° 需重试，防止靠转身直行替代横移。
3. 转向轮：先沿通道行驶，再在外侧转弯区绕过材料区，反向停靠。理解转向需要位移，A/D 只改变前轮角度，W/S 才驱动车辆。

开始、暂停、继续、重试、下一关组成完整流程。过关要求检查点、目标距离 ≤ 0.23m、朝向误差 ≤ 8°、停止 ≥ 0.6s、完整车身无干涉。碰撞即刹停并计次；重试清空本次数据。用时仅作记录，星级奖励少碰撞和紧凑路线。关卡锁定目标与障碍物；最佳星级只保存于本机。

机构观察不自动驾驶；短时预设动作和慢速行走由用户启动，结束回到可继续观察的位置。离屏/失焦停止，闯关暂停；减少动态效果时相机直接就位，保留用户主动操作。移动端保留真实按钮和滚动空间。

## 十二关扩展与面板调整

基础三关保留，新增三个阶段共九关。难度来自连续路线决策、完整车身通过窄道、指定朝向检查点、停车确认与倒车，而非单纯加快计时。终点精度逐步收紧，后期加入碰撞次数限制，最后一关需要沿双弯路径倒车返回。

检查点的地面圆环和朝向箭头与判定共用同一份坐标。当前点用蓝色，后续点低对比显示；带停车要求的点增加金色外环。每一关均有实际轮速与转角命令组成的可达路线，验证过程中不设置位置或跳过检查点。

面板取消撑高的空白区域，按内容决定高度；将重复的横移按钮与差速自转按钮收起，用五向或七向控制盘表示本底盘实际动作。机构观察增加速度读数和即时运动解释；闯关分为阶段选择、任务、控制、停靠反馈与可折叠路线。保留高屏内容自然排布、低屏面板滚动与手机触屏操作。

## 操纵与行走实验台改版

复用现有 Hero 三维机构与零件装配。右栏围绕输入、模型证据和验证组织：轮式调参卡、实时运动读数、九个预测实验；行走方式使用连续时间轴、四个关键姿态、接地证据与机构观察工具，替换只改变文字的地面情景菜单。履带金色标记直接附着在同一编号链板；足式支撑图形连接当前接地足的实际坐标；轨道侧移试验展示受约束的输入与零侧向位移。

新增可见部件仅为链板表面标记、足端支撑区域和轨外目标地面标记；主体零件沿用上方清单。时间轴和三维姿态共享纯函数，预测实验从实际起止位姿判定。
