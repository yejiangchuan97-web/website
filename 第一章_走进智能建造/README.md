# 第一章 · 走进智能建造

**[打开章节入口](index.html)** · [课程总览](../index.html#chapter-1) · [第二章入口](../第二章_动力与工作机构/index.html)

入口延续前面章节的蓝白风格：教学楼、挖掘机、喷涂机器人三个概念展品，配合任务卡、学习导览和章节总结。可拖动环绕、点击选读、逐站巡展或暂停模型。

本章原来只有三份教学方案。本次提供三份任务导读，每份包含四个阅读主题、要点对照、思考提示及继续学习的线索。原教学方案保留，方案中的设备与场景交互尚未制作。三份导读独立阅读，默认深色，支持浅色切换、同章导航与返回总览。

构建：`node scripts/build.mjs 1`。打包：`python scripts/package-chapter1.py --output <输出目录>`。

入口源码在 `src/`，导读内容在各任务的 `src/guide.json`，共用模板在 `公共资源/认识智能建造/`。输出 HTML 内嵌脚本、样式和三维依赖，可离线打开。入口沿用固定 16:9 版式，导读使用响应式阅读布局。

浏览器检查：安装 Playwright 后运行 `node scripts/check-chapter1.cjs`。离线包加 `--site <site目录> --packaged`，可用 `--screenshots <目录>` 保存预览。
