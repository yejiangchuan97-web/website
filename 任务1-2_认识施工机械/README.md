## 教学方案与实现说明

## 原文锚定与资源选择

来源：[飞书任务原文](https://my.feishu.cn/wiki/ZHmNwLwLXiKgvVktJjvcNHvWnHd#I0XedxfLlo7K6exv1gUcgaUtnie)。锚定六类机械、施工阶段与机械分布、危险能量和运动区域，回应“给新设备归类”“吊运钢筋、人员上楼、加工长度、加工形状的匹配”。

适合做**设备观察台＋工作装置热点＋用途匹配卡**。挖掘机、塔吊、泵车值得有简化三维动作，其余机械用可旋转模型、侧视动画或实物照片即可。真实性来自工作装置与作业对象对应，不靠堆积设备数量。

## 页面形态

左侧是教学楼施工阶段，中央是设备观察台，右侧先显示“作用对象、动作、工作装置”三个可翻开的小卡。设备名称可暂时隐藏，学生可以先看动作再识读名称。底部有“看装置”“派工作业”“看运动范围”三个独立入口，按需要切换。

初版包含挖掘机、塔吊、人货施工升降机、泵车、搅拌车、钢筋调直机、切断机、弯曲机；装修与辅助运输设备以补充卡呈现。设备用统一比例尺提醒尺度，观察台不要求所有模型保持同一画面大小。

## 逐项交互大纲

1. **工作装置带出用途。** 学生点挖掘机铲斗、泵车管口、切断机刀口或弯曲机销轴，其他部分半透明，工作装置慢放一个短周期；材料分别被挖起、输送、切断或弯折。理解“用什么部件，直接对什么材料，完成什么动作”，不是仅按外观分类。
2. **同一材料、不同动作。** 将“钢筋变短”和“钢筋弯成箍筋”卡拖到加工设备上，正确匹配后出现前后材料对比，交换设备则显示动作不满足要求的原因。加工动画只表现运动关系，保留防护罩轮廓，不能成为伸手操作范例。
3. **吊物与载人有不同条件。** 钢筋吊运卡对应塔吊；人员上楼卡对应题目明确给定的合规人货设备。若学生把人员卡放到吊钩下，画面停止并解释用途不符，不播放危险载人动作。重点识别用途，不通过外形推断载人资格或额定能力。
4. **设备能跨阶段服务。** 拖动教学楼阶段条，塔吊可在主体阶段吊钢筋，也可在装修初期运输材料；标记“主要工序”和“辅助工序”。泵车行驶与泵送分别播放，提醒归类依据是主要任务，不是设备是否有车轮。
5. **危险区域随运动而变。** 点击挖掘机回转或塔吊吊运路线，显示尾部、臂架、吊物经过空间的半透明扫掠体；拖动第二台设备或人员图标，观察交叉区域出现。学习区分固定危险区、运动扫掠区与临时交叉区，示意区域不附伪造的通用安全距离。

## 最先做的演示

先完成“挖掘机铲斗挖土”“塔吊吊钢筋”“切断与弯曲对照”四个可暂停片段，以及四项原文作业卡匹配。再加入泵车：一键切换底盘行驶、臂架布置和混凝土流动，清楚分开行走、定位、泵送三种动作。

扩展可用智能梁场视频做“找设备”热点时间轴；学生点片段中的设备后填写用途依据。真实视频、截图及产品模型仅作为待核对的参考，不默认取得网页发布授权。
