保留教学网页、源码、构建脚本、公共库及许可证、实际使用的教学素材，以及正式测试代码、测试输入和操作步骤。公共库是构建所需文件，不能当作本地环境忽略。

2026-10-21 起，检查截图、自动报告、实验导出、旧修改前副本和重复公共库取消 Git 跟踪，原工作目录中的文件仍保留。`.gitignore` 防止这些文件再次加入。历史提交未重写，因此已有历史中的文件仍可查到。

`qa` 不是整体忽略目录。`fixtures`、`source`、操作步骤 `*actions*.json`、任务6-2的 `motion-order.json` 和测试脚本仍被跟踪。报告汇总脚本可能要求先运行对应检查来生成本地报告。文档中的历史截图和报告路径属于本地验收记录，新克隆不包含这些产物。

教材来源资料继续作为方案依据保留。任务5-3的历史源码仍被任务6-1构建引用，不能直接移除。

- `公共资源/vendor/three-r160.min.js`：Three.js r160 的唯一公共副本，附 `THREE-LICENSE.txt`。
- `公共资源/anatomy/`：四套内容相同的绘图工具合并到此处；同时保留原有两种许可证文本，避免改变页面内嵌许可。

各页面继续内嵌所需的 JavaScript 和样式。共用源码不改变单页离线使用方式，也不增加 CDN 依赖。页面导航、视频等外部本地资源仍需随目录保留。

## 构建和检查

整个仓库共用电脑上的 Node.js 和 Python，无需为每个任务安装一套环境。当前构建脚本使用 Node.js 内置模块，链接检查使用 Python 标准库。

```text
node scripts/build.mjs all
node scripts/test.mjs
python scripts/check-links.py
```

也可用 `node scripts/build.mjs 4-2` 单独构建某个任务。成品 HTML 保持跟踪，构建后应连同相关源码一起提交。

历史浏览器检查脚本依赖开发机器上的浏览器及 Playwright，部分含个人路径；这些路径不影响网站运行。浏览器和依赖安装目录不应提交。将来统一这些历史脚本时，应使用根目录的一份依赖配置，不要在任务目录中分别安装环境。

`src/scene-cache.json` 是可再生成的几何缓存；全量构建不依赖已有缓存。检查产物、整理清单和本地验证副本分别保留在原位置及 `.local/`，均不上传。
