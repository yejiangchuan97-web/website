# 课程首页 · 八章转台与章节镜头

[打开课程](index.html)

首页是一个全屏三维舞台，有两个镜头状态，地址决定显示哪一个：

| 状态 | 地址 | 画面 |
| --- | --- | --- |
| 概览（封面） | `course/home/index.html` | 纯左右布局。左侧：书名（一行、单色）、大号数字“08 学习章节 / 24 互动任务”、导语、两栏八章目录（当前章右侧有进入箭头，点章名转到这一章，再点进入）和“开始学习”。右侧：八章主展品围成一圈，当前章放大在最前并循环本章标志动作，其余七章缩小、略褪色、隐约可见。一张截图就能看到全书结构 |
| 章节 | `course/home/index.html#chapter-N` | 与封面同样左右布局。左侧：第几章、章名、大号数字（任务数 / 第几章）、一句话、任务列表（任务名 + 一句话看点，整行可点）、上一章 / 下一章（带小图，直接切换）。右侧三维和封面一样：本章主展品在前居中，其余任务展品沿身后一道弧排开 |

画面分三层：最底下是页面自己画的背景（冷白渐变、左侧图纸网格、衬在展台后面的章节大数字，颜色取本章识别色）；中间是透明的三维舞台（只有展品、阴影、主展品脚下的光斑和转台地面上的一圈刻度盘）；最上面是文字。三维画面在左栏下方渐隐，不压文字。

- 封面目录：两栏八章，细线分隔；每章一行小段表示任务数，本机做过的任务变绿并显示“已体验 x / y”；当前章浮起成卡片。
- 展台编号牌：每件展品脚下一枚章号，当前章展开成“章号 + 章名 + →”，点它进入本章；点其他编号牌把那一章转到前面。被主展品挡住的编号牌自动收起。
- 章节任务卡：左侧是该任务展品的小图（展台离屏拍的），右侧任务名、编号和一句话看点。

章节封面就是首页里的“章节”状态，进出任务都经过它：

- 进入：点击正前方的主展品、章名或“进入本章”，地址变成 `#chapter-N`。
- 去任务：点击任务展品（模型、底座或下方名称标签都算）或任务卡片（整张可点）。悬停展品时它放大抬起，名称标签展开显示任务名与本机完成情况 ✓，对应卡片同时高亮。
- 从任务回来：任务页左上角“← 主页”指向 `course/home/index.html#chapter-N`，直接落在本章，并有一个短暂的拉远。
- 回到概览：“← 全部章节”或 Esc；浏览器前进、后退跟随地址。
- 旧地址 `course/chapters/0N/overview/index.html` 保留为跳转页，转到 `#chapter-N`（由 `redirect.mjs` 生成）。

## 切换章节

概览中：按住鼠标左右拖动转台（松手吸附到最近的一章）、滚轮、← / → 键、点左侧目录或点旁边的展品，都能把那一章转到前面；再点一次（或点目录里已选中的那一章、Enter）就进入；“开始学习”进入第一章。展台不自动轮换。减少动画时模型不动、镜头直接切换。

章节中：Tab 或 ← / → 在任务卡片间移动，Enter 进入任务，Esc 返回概览。

每章有一个识别色（`exhibits.js` 的 `tint`），只用在小图底色、展台边缘细环和主展品脚下的光斑上；按钮、链接和文字仍用全课程统一的蓝色。

## 各章标志动作

| 章 | 主展品（对应任务） | 循环动作 |
| --- | --- | --- |
| 一 | 挖掘机（1-2，课程机型模型） | 转向料堆、落臂、收斗杆装料、抬臂回转、翻斗卸料 |
| 二 | 柴油机（2-1，原第二章封面展品） | 三缸活塞上下、曲轴转动 |
| 三 | 六轴机械臂（3-2，与第一章机器人展厅同一模型） | 在两个料位之间往返取放一块料，夹爪张合，料块随末端移动 |
| 四 | 激光雷达小车（4-2） | 扫描头连续旋转，带一片扫描扇面 |
| 五 | 钢筋绑扎机械臂（5-2） | 在交叉点之间转动，停下时下压、绑丝盘转动、绑扣闪亮 |
| 六 | 喷涂机器人（6-4） | 喷枪沿墙面上下往复，带喷雾锥 |
| 七 | 立面巡检无人机（7-2） | 沿建筑立面逐行飞过，旋翼高速转动 |
| 八 | 安全展台（8-1） | 警戒栏两盏警示灯交替闪烁，安全帽在展台上缓慢转动 |

进入章节后，本章其余展品运行各自原有的动作（齿轮、皮带、丝杠、扫描等）。所有动作只为看清结构与用途，不表示真实设备的速度、精度、性能或安全条件。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.template.html` | 页面骨架；`scripts/build-course-cover.py` 生成 `index.html` 与 `data.js`（章节、任务、入口都来自 `course/catalog.json`） |
| `stage.js` | 三维舞台：离屏渲染器给展品拍透明底小图（`HomeStage.thumb(章, 任务)`，空闲时逐张拍并缓存）；转台、聚焦与褪色、概览时只用书名右侧的画幅（虚拟画幅随推近铺满全屏）、推近/拉远、拾取（先打网格，再看展品投影框四周 12px）、名称标签锚点 |
| `exhibits.js` | 每章主展品与任务展品的对应关系、朝向，以及八个标志动作 |
| `app.js` | 地址路由、文字层、左侧目录、键盘/滚轮/轻扫、任务卡片、“全部任务”搜索、本机进度 |
| `home.css` | 背景层、版式与深浅色。识别色 `--tint` 写在元素上，文字色 `--tint-ink`、浅底 `--tint-soft` 由它派生。宽屏页面高度 = 视口高度（`100dvh`），不锁 16:9，左栏与右侧三维上下对齐；900px 以下（手机、平板竖屏）三维在上、章节信息在下，整页滚动 |
| `task-notes.json` | 每项任务的一句话看点（不超过 18 字），构建时并入 `data.js`；新增任务必须补上 |
| `redirect.mjs` | 生成各章 `overview/index.html` 跳转页 |

展品模型全部复用课程已有模型：`shared/workshop/machines.js`、`machine-models.js`、`six-axis.js`（挖掘机、六轴机械臂、发动机）、`shared/chapter-cover/safety-maintenance-models.js`（安全展台）、`shared/chapter-cover/cover-models.js`（原第二～七章封面展品，几何与材质原样迁移，只为动作挂出几个节点）。它们都是课程原创的教学概念模型；首页不加载第三方模型文件。三维库为 `shared/vendor/three-r160.min.js`（MIT，许可见 `shared/vendor/`）。

本机进度只读：任务页外壳把各工位完成情况存在 `localStorage['c2-progress-任务号']`，首页数出已完成的工位数显示为 ✓。

没有 WebGL 时，概览右侧显示八张章节卡片，章节状态显示任务卡片，链接全部可用。页面支持 HTTP 与 `file://`。

## 构建与检查

```bash
node scripts/build.mjs 1-entry
```

（任一 `N-entry` 都会重建该章跳转页，并运行 `build-course-cover.py` 与 `finalize-pages.py` 重建首页。）

```bash
node scripts/qa/home-zoom.cjs
```

需要先 `npm run serve`（或用 `BASE=` 指定地址）。它在 1920×950、1440×810、1366×640 的浅色与深色下检查不滚动、文字字号、进入章节、悬停、点击模型进任务、从任务返回、旧地址跳转、`file://`、无 WebGL 与减少动画，截图写 `artifacts/screenshots/home-zoom/`，结果写 `artifacts/reports/home-zoom.json`。
