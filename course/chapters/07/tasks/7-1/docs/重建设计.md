# 桥梁巡检三维现场 · 2026-10-23

对照用户指定会话 01a163ec-8ded-7bd1-930d-8c017a00cdc1 的最终腻子打磨工坊，以真实透视 Three.js、圆角实体、自然光影和单屏操作重建。anatomy 用于物理构件、动作同源、近景细节及实际截图审查；本项目不使用其 SVG 深度排序引擎，不声称通过该引擎的几何审计。

## 一句话概念

三台机器人沿同一座桥的桥面、检修楼梯和钢梁表面抵达三个检查点，学生用机器人上的相机留下可定位、可辨认、可复查的证据。

## 先看懂巡检，再理解机器人的作用

- 巡检委托：青溪桥雨后日常巡查（虚构教学场景），检查排水及可见外观异常，不开展结构安全评级。
- 排水口：轮式平台在桥面平顺移动；看到杂物和积水，留全景与近景，安排清理，再复拍确认通畅。
- 桥台侧面：四足平台经过检修台阶；看到水迹，只能记录现象并安排排水检查及跟踪，不能从一张照片推断成因。
- 钢梁：磁吸爬壁平台在相容钢面附着，接好防坠系绳后移动；看到涂层线状异常，记录位置并提交专业复核，照片不能直接证明钢材裂缝或安全等级。

## 空间与实体

所有几何使用米、Y向上；桥面、楼梯、检修平台、墩台、钢梁与河道相接，镜头可以在整体与局部之间自由移动。实体清单分别见 qa/world3d-parts.md 和 qa/robots3d-parts.md。主体不仅有外壳，还包含轮胎轮毂、关节壳与连杆、足垫、磁吸轮、相机云台、镜头、紧固件、线缆和保护绳。桥梁具有真实厚度、支撑、栏杆底座、排水构件、接缝及表面病害纹理。

## 操作与证据

16:9 桌面工作台：上方四步导航，左侧约3/4三维现场，右侧随任务变化的操作面板；手机改为场景与操作上下排列。使用全桥、跟随、部位、机体近景，拖动旋转与滚轮缩放。轮式轮转、四足步态、爬壁姿态和路线进度由同一状态驱动。

采集相机从现场三维渲染，不用独立SVG照片替代。拍摄时记录相机视角、曝光与位置以及原始快照；之后调镜头或处理病害不会改变已拍照片。记录引用确定的照片ID，复查照片关联原记录。运动中拍摄、没有到位、偏离目标、太暗或拍不到细节都给出具体反馈，并允许重新拍摄。
