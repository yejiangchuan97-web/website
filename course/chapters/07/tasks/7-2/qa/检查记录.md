# 任务 7-2 检查记录

日期：2026-10-22。范围为本任务新建的离线页面、教学模型与三维场景。

## 已验证的教学流程

- 规划航点与航线预演；预演不自动制造照片记录。
- 远拍、快速掠过、斜拍和清晰对照；距离、曝光、拖影与质量结果采用同一模型。
- 不合格照片不能完成分类复核，选择补拍可以得到对应反馈。
- 六点位采集、两类误报排除、未检出照片中的人工疑点落点、依据填写及完整交付。
- B3 需将人工点位落在本教学图像的裂缝轨迹附近，单独勾选复选框不能完成任务。
- 补拍保留旧图，旧意见不自动转移到新图；可打开前次与本次采集的并列对比。
- 复核页的读数与三维机位采用正在复核照片的参数，不误用尚未采集的参数设置。
- JSON 导出各版本合成图像、参数、质量、当前和历史意见；CSV 导出记录并转义可能被表格软件当成公式的输入。
- 页面重载恢复本机进度；缺少记录人时交付状态为草稿。
- 近拍练习在共面、边界清晰且沿规定断面落点时输出比例换算值；默认 8 px 对应 2.00 mm。清除落点同步清除导出结果。

## 验证边界

本页采用 Three.js 实体网格和深度缓冲，参考 anatomy 的实体细节与图卡设计。检查使用本页的模型和浏览器脚本；没有把它称为 anatomy 原生 SVG recorder/turn 审计，也不宣称已证明所有实体接触与任意视角的几何净空。
