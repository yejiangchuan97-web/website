# 任务8-2 · 保养排查

[打开当前课堂](index.html) · [本章入口](../../overview/index.html) · [项目说明](../../../../../README.md)

维修车间里的四个班后维护工位，流程相同：停机 → 隔离（拔钥匙/断电挂牌）→ 能量确认（冷却/泄压）→ 处理 → 复查 → 交接记录。前两个工位在三维模型上逐点检查、核对资料与材料；后两个是管路清洗，能量确认就是泄压到压力表回零。

- **发动机点检**：第二章 2-1 的四缸柴油机放在发动机支架上。检查机油尺、冷却液壶、附件皮带、底部与地面；情境有班后点检、底部渗油、皮带裂纹、机油规格不明。
- **挖掘机润滑**：第二章 2-1 的挖掘机。铲斗落地、先导锁定、释放残压后，检查并加注六个铰点的黄油嘴；情境有班后润滑、动臂油缸渗漏、铲斗销松旷、润滑脂资料不明。
- **喷涂管路清洗**：第六章 6-4 的喷涂机器人。停止喷涂 → 断电挂牌 → 喷枪上锁、开泄压阀（压力表回零）→ 按涂料类型选清洗液（水性用清水，油性用配套溶剂）→ 吸料管从涂料桶移到清洗桶 → 摘牌送电低压循环冲洗，看样杯由涂料色变清后停泵 → 重新断电泄压 → 拆洗喷嘴、枪内滤网、吸料滤网 → 灌保护液或排空 → 废液倒入回收桶。压力没回零就拆枪会提示高压注射伤并被拦下。情境有水性涂料、油性涂料、喷幅变窄（枪内滤网堵）。
- **砂浆管道清洗**：本页新做的教学螺杆式砂浆泵（通用造型，无品牌）：带格栅和搅拌轴的料斗、减速电机、螺杆泵（定子剖开一角可见橡胶衬套和转子，剖面浅杏色）、出口压力表与泄压口、四段输浆管与管卡、喷枪与喷嘴、清水桶、沉淀桶、清洗球。停止上料、泵空料斗 → 断电挂牌 → 反转泄压 → 清水冲洗料斗 → 喷枪出口对准沉淀桶（不对人、不进下水口）→ 塞清洗球、清水推过整条管 → 重新断电泄压后拆洗喷嘴 →（冬季）放空存水。停泵后开始课堂计时，管内残浆按段变硬（颜色变化，越靠喷枪越快），等太久就堵管：推球时压力表异常升高、堵段发硬，要泄压 → 分段拆管 → 敲击疏通，带压拆管会被拦下。复查要出口清水、料斗和管路无余浆、管卡密封完好。情境有班后正常清洗、午休忘洗已结块、冬季停用一周。

每个工位 4 张“试一试”。交接记录四个工位共用、跨工位保留（localStorage `course-maintenance-v2`，旧版只有两个工位的存档会自动补齐），可导出为 JSON，清空前需确认。清洗工位遇到关键时刻（开始冲洗、拆下零件、堵管、推出清洗球）镜头会自动拉近，按“全景”回到全图。

## 模型与资料

内容来源与模型说明（保存在仓库外的 教材文档/）。机型为课程原创教学模型；检查结果、材料与温度、压力读数都是课堂案例，不代表具体机型的维护规程、换油周期或润滑用量，也不生成真实设备放行或维修许可。清洗工位的计时（课堂秒）、压力（压力表“格”）和颜色都是课堂示意，不代表真实初凝时间或泵送压力；清洗介质与顺序以设备与材料说明书为准。砂浆泵输浆管画成半透明，是为了看到管内残浆（示意）。
