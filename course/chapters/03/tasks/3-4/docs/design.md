# TCP 三维工具实验台 · Anatomy Hero

日期：2026-10-21。一个六轴机器人工作台；六件可换装工具属于同一运动主体。左侧工具陈列、中央真实三维机械、右侧操作、底部现场读数。直接沿用任务 3-2 的几何尺寸、六关节运动链和正逆运动学，以 Three.js 深度缓冲承接原有三维模型；采用 Anatomy 的实体零件、材质层次、真实接触、细节与缓动原则，不另换成与原机器人不一致的 SVG 运动链。工具柜缩略图由同一三维工具几何产生。

## 物体与教学映射

学生换上一个工具，观察法兰连接处与真正工作点的距离；改变姿态时，同一机械臂分别围绕法兰和 TCP 运动，指针与轨迹用同一正解计算。四点法把工具尖端放到同一固定针尖，用四组不同的法兰位姿反求偏置；第五姿态独立复核。错误参数有真实几何偏差，不用人为移动标记。

## 约束与验证

内部长度 mm、角度 degrees。法兰坐标采用 3-2 固定约定；工具可视化局部 +Z 经固定旋转映射到法兰 +X，参数必须明确是法兰系分量。TCP 并非外形中心，夹爪与双吸盘的中心允许为空间虚点。四点法只求位置，不求轴方向。0.5 mm 仅为本练习阈值。

校验范围：模型中的真实尖端、法兰/工具变换、绕点保持误差、六种工具外形与数据一致、四点拟合与重复姿态拒绝、第五姿态、状态重置、桌面/手机、键盘、浅深主题、减少动态、离线与无 WebGL。Anatomy 的 SVG painter-order 与 turn-kit audit 不适用于既有 Three.js 网格；以深度缓冲、数值运动学检查与多角度截图检查本页，不宣称通过该 kit 的几何审计。

## 实际检查结果

模型检查覆盖六种工具 × 两种转动方式 × 89 个角度，共 1,068 个姿态。工作点保持误差最大 0.02463 mm，法兰保持误差最大 0.01104 mm，六工具四点反求的偏置误差最大 0.07839 mm；均为教学数值模型结果。错误喷枪参数用于夹爪时，所选点与实际点距离 63.6396 mm，20° 姿态改变带来约 15.6283 mm 的实际工作点位移。

浏览器检查覆盖 23 项，记录见 `../qa/verification.json`。包含本机直接打开、六工具可视工作点与运动学一致、两类绕点转动、错参数、四点采集及第五姿态、导出、两类错误样本、闯关、停止后重启、真空与接触分离、笔记本、手机固定视区、减少动态、静止后停止绘制、无 WebGL 回退及无未捕获异常。

通过 Anatomy 的 capture/drive 工具补充浅深主题末端连接处 4× 截图，见 `../qa/shots/junctions-4x-light.png` 和 `junctions-4x-dark.png`。材质与接口按原六轴实体风格延续；工具适配盘与法兰连接面已按实际几何接合。无 WebGL 采用同一网格的静态 SVG 投影，视觉精度与交互性能不等同 WebGL 模式。
