# 任务 1-2 · 认识施工机械

[打开任务页](index.html) · [第一章封面](../../overview/index.html)

统一任务页外壳（与第二～八章相同）：页头本章任务 → 工位条 → 三维区 + 操作面板 + 试一试。

| 工位 | 展品（三维区上方切换） | 试一试 |
| --- | --- | --- |
| ① 土方机械 | 挖掘机、推土机、装载机 | 挖掘机转身、抬推土机铲刀、装载机举臂收斗、三台都点出干活的部件 |
| ② 起重与输送 | 塔式起重机、施工升降机、混凝土泵车 | 塔吊起重臂回转、吊笼升到高处、泵车三节臂都动、找出泵车支腿 |

- 三维区左上角：全景、俯视、展开结构、环绕；底部：播放预制动作、单步、复位、快慢和读数。
- 面板：当前展品的部件按钮（点一下高亮并显示名称）、机构滑杆、试一试；最底下一行是模型来源和许可。
- 动作是教学结构示意，不代表实机性能。

展品配置在 `src/config.json`；工位编排在 `src/stations.js`、`src/stations.css`；三维展品和模型仍由 `shared/workshop/hero-gallery.js` 等原展厅脚本提供。
构建：`python scripts/build-workshops.py 1-2`，再 `python scripts/finalize-pages.py`。
