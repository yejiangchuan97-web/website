传动角、死点与闭合关系 · 教学说明
传动角、两种死点与参考力工况

本页 μ 取 B/C 两条轴线的锐角，必要时画出延长线。假设 B 为无自重、无惯性的二力杆，P 点仅作无载示踪。参考工况取 B 受压 / 受拉的轴向力 |F_B| = 100 N；这是方向与分力示例，不是从电机转矩或夹持负载求出的真实力。几何播放与参考受力独立，参考箭头不用于决定播放方向。

V 点所受力沿 B：F = F_t + F_r。切向分量 |F_t| = |F_B| sin μ，输出力臂 |r_C| = C sin μ，|M_C| = |F_B| C sin μ；计算转矩时 mm 换算为 m。逆时针为正。径向分量不产生 C 轴转矩，主要影响轴承反力。给定 F_B、C 时，μ 越接近 90°，可用转矩越大；μ→0 时，B/C 共线，有限 F_B 的输出转矩趋零。若指定输出转矩不变，所需 F_B 会随 μ 减小而增大。sin μ 是切向力比例，不是能量效率。

A/B 共线是另一种情况：B 的力线经过 O₁，C 反驱 A 时，对 A 的力臂为零。A 作主动曲柄通常仍可在同一支路通过，C 在此瞬时停转并换向；此时 B/C 传动角不一定小。图中 r_A 只在接近 A/B 共线时标出。不要把“死点”解释成所有驱动方向都无法运动。

15°、40°和 A/B 夹角 5°仅用于分级教学提示，并非通用设计限值。B/C 共线、两交点合并处仍使用原有数值隔离，不画成已达到 μ=0 的精确姿态；杆长、机架与装配支路始终不变。参考：METU 四杆传动角及摇杆死点 · Union College 力分解与传动角。

|O₁U| = A　 |UV| = B　 |VO₂| = C　 |O₁O₂| = D

给定 θ 后，V 必须同时位于以 U 为圆心、B 为半径和以 O₂ 为圆心、C 为半径的圆上；选择其中一个交点，才确定装配支路。P 固定在连杆局部坐标中，随 B 一起运动。

尺寸编辑属于重新装配实验。演示和拖动只改变输入角，始终保留杆长及分支符号。不可达区不能跨越；两交点合并或圆心近重合时，在隔离区前停住并允许反向，绝不自动换支。几何交叉由不同深度层区分，未做实体碰撞和动力学仿真。

连续性保护与参考

采用解析圆交点和当前输入角所在的连续可达区间；交点到 U→O₂ 轴线的距离 h 不低于 0.75 mm，两圆心距离不低于 1 mm。这是数值隔离设置，不能解释成真实机构的实体限位。全周可达且无奇异点的机构可连续旋转；边界处减速停止。
