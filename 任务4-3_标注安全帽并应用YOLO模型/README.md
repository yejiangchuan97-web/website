## 教学方案与实现说明

**统一入口：[安全帽与 YOLO 教学实验](index.html)** · [直接进入预测](index.html#predict) · [直接进入评估](index.html#evaluate) · [本章演示入口](../公共资源/感知与识别/index.html)

当前交付将标注、预测、评估三个实验合在一个离线 HTML 中。**直接把 `index.html` 发给别人即可**，无需同时发送另外两个页面或素材文件；顶部导航始终显示全部三个实验，切换时保留当前操作。`predict.html` 与 `evaluate.html` 兼容旧入口，也各自包含全部三个实验。

三个实验使用统一的 **16:9 教学画面（逻辑尺寸 1440×810）**，随窗口等比缩放，支持全屏演示；手机建议横屏。主要操作和评估指标保持在画面内，检查器及候选列表可内部滚动，补充说明、课堂挑战和 IoU 演示在“知识与练习”中。施工图增加了橙、蓝、青绿等工作服配色，头部位置、帽子状态与标签坐标保持一致。

标注实验用于人工画框与 YOLO 标签；预测实验观察固定候选与分数阈值；评估实验核对真值、误检、漏检与指标。预测与评估使用教学设定，浏览器未运行真实 YOLO 推理。原规划的三维拍摄台、数据划分与裂缝量测保留为下文课程拓展规划。

修改源码后，在仓库目录运行 `node scripts/build.mjs 4-3` 可重新生成三个离线入口。

## 可以做的交互点

| 知识点 | 用户操作与视觉反馈 | 学习意义 |
| --- | --- | --- |
| 网络学习示意 | 将像素小块送入简化分层网络，单步播放预测、与标签比较、权重更新；切换训练/推理路线 | 权重在训练时调整，推理用已有权重；显示的特征图只是教学示意 |
| 四种标注形状 | 同图切换点数钢筋端头、折线记裂缝走向、矩形定位头部、多边形圈剥落 | 先按所需信息选形状；线和框不直接提供裂缝宽度 |
| 安全帽统一口径 | 拉框、改类、删重复、标待复核；叠加帽体框、头部框、整人框供比较 | 0=hardhat围绕可见头部及所戴帽，1=no-hardhat围绕可见头部；不框躯干，不把遮挡看不清当未戴帽 |
| YOLO归一化 | 拖动框角，实时显示像素端点、中心与归一化TXT；缩放查看窗口后TXT保持不变 | 横向除原图宽，纵向除原图高；标签无置信度，文件同名、行数和类别表须对应 |
| 分组划分数据 | 将不同地点/批次卡片拖入训练、验证、测试；同视频近邻帧/原图副本绑定提示泄漏 | 按来源独立性安排用途，不能把相近副本当新测试；增强仍留训练组 |
| 模型、阈值与结果 | 固定同图及模型，叠加0.25/0.50预测；逐个将真实头部与预测配对，显出误检、漏检、重复与错类 | 框的分数不是整体准确率；提高阈值可能同时去掉误检和真目标 |
| 裂缝尺寸边界 | 用原图同平面标尺两端定比例，再沿垂直裂缝方向取局部宽度；切换远近图重新标定 | 检测框不等于裂缝边界；像素到毫米需尺度与成像条件，无法标定时只给像素读数 |

## 布局与演示样例

中央大画布支持原图/标签/预测三层开关，右侧是类别口径和字段解释，底部为目标对应列表。导出TXT与原图配对，结果回放保留模型与推理设置，人工复核另存，不把模型框静默变成真值。

例一使用原文640×640图的（160，80）—（320，240）框，联动显示`0 0.375000 0.250000 0.250000 0.250000`；换成长方形原图，观察横纵不同分母。例二并排核查同图两档阈值，按原文设定10个真目标、8个预测、6个正确理解75%精确率和60%召回率；该设定与实测结果分开，没有预测时精确率显示“不适用”。裂缝示例用10毫米/200像素标尺和6像素截面解释0.30毫米，仅标为设定案例。

## 首版与扩展

先做标注、TXT导出与校验、来源分组、预测回放复核；训练动画仅说明机制，不声称浏览器已训练YOLO。真实推理可对接现有RobotVision输出的原图、标注图、CSV和JSON，核对01号两类安全帽模型及图片来源。以后有经转换验证的浏览器模型再提供离线推理；真实训练需独立后端及训练记录，与教学回放明确区分。裂缝15张分类素材未补检测真值前，不计算检测mAP。

## 连通与能力边界

接[4-2雷达](../任务4-2_机器人激光雷达感知/README.md)的Route-A位置，将画面关联到观察点，而不声称无深度图像框可直接成为世界坐标。给[7-2病害复核](../任务7-2_无人机巡检_病害检测与数据复核/README.md)提供疑似区域、原图来源、像素选点与标定条件；给[8-1安全操作](../任务8-1_机械与机器人的安全操作规程/README.md)提供待复核佩戴状态。共享类别表按项目命名，安全帽0类和裂缝0类不混用。默认素材可独立打开；预测只能提示复核，不能据一张模糊图确认违规、构件安全或真实裂缝尺寸。
