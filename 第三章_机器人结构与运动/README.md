# 第三章示范入口与统一版式

[打开第三章总入口](index.html)

[查看封面预览图](封面预览.png) · [本轮检查记录](检查记录.md)

本章覆盖五项任务、六个实验页面。总入口使用统一的蓝白配色与三维展台，可拖动环绕、点击展品预览、逐站巡展，再由任务卡直接进入实验。任务 3-3 分为“减速器”和“运动转换”两个入口。

## 一套固定的教学画面

所有页面以 **1600 × 900（16:9）** 为设计画布。根据窗口等比例缩放并居中，窗口比例不同则保留边缘留白；主页面不设置上下滚动。

| 区域 | 统一规则 |
| --- | --- |
| 顶部导航 | 64 px；章入口、六个案例链接、说明、主题与全屏 |
| 任务标题 | 94 px；任务编号、30 px 中文主标题、一句话操作目标 |
| 学习活动 | 66 px；54 px 高的大按钮、19 px 文字，固定在模型上方 |
| 实验工作区 | 左侧模型，右侧 440 px 操作与反馈；间距 18 px |
| 页脚 | 38 px；操作路径、观察提示与返回章入口 |

以浅蓝灰底色、白色面板、深蓝文字构成基础层次；蓝色表示当前活动与主要操作，青绿色表示正常反馈，橙色保留给需要关注的变化。采用微软雅黑、苹方及系统字体，不依赖在线字体。

页面内容超过单屏容量时，按学生正在做的事情分成可切换的操作面板；主要控件保持在同一个工作区。说明与详细采集记录通过独立弹层查看。模型视角、读数与停止操作持续保留。

## 各任务的落位

| 任务 | 上方主要活动 | 右侧内容安排 |
| --- | --- | --- |
| 3-1 构型与工作空间 | 原四项活动整体移到上方，五种构型放在模型上方 | 操作控制／学习任务；点动、行程与工具、空间目标分别切换 |
| 3-2 六轴点动 | 四项学习活动置顶 | 点动控制／学习任务／速度与工具 |
| 3-3A 减速器 | 各减速机构直接切换 | 运动观察／实验与零件／动手挑战 |
| 3-3B 运动转换 | 各转换机构直接切换 | 与减速器使用同一版式 |
| 3-4 末端与 TCP | 工具换装／理解 TCP／四点标定／实战闯关 | 姿态对照与工具参数分区；采齐四个姿态后自动显示计算与复核 |
| 3-5 移动底盘 | 轮式驱动／越障机构／驾驶闯关 | 操纵、观察、验证分区；开始关卡后自动显示驾驶控制 |

## 文件与维护

- `src/page.html`、`style.css`、`app.js`、`scene.js`：章封面源文件。
- `../公共资源/机器人构型与运动/src/chapter-layout.*`：六个实验共用的版式与导航。
- 各任务的原模型、计算与操作逻辑保留在各自 `src/` 内；构建时嵌入共用版式。
- 构建后的 HTML 各自包含样式、模型库和脚本。保留现有目录关系即可离线切换。

更新封面：`node scripts/build.mjs 3-entry`。更新单个任务：`node scripts/build.mjs 3-1`，依次至 `3-5`；其中 `3-3` 同时更新两个实验页面。

打包已生成的第三章页面：`python scripts/package-chapter3.py`。输出位于 `dist/chapter3-static-时间戳/`，包含可直接上传的 ZIP 与展开后的 `site/`。包内以 `index.html` 为新版章封面、`lessons/` 为六个实验，路径均改为英文文件名；包含离线使用说明、封面预览图和组件许可证。

本次调整用于第三章案例的界面与演示。页面中的结构、运动与标定数据仍为教学仿真，不作为实机性能或工程验收依据。
