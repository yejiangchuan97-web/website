## 四关任务

| 关卡 | 学生操作 | 学习结果 |
| --- | --- | --- |
| 稳住接触力 | 让墙面试块凸起，对比固定位置与反馈退让，记录接触力和退让量 | 理解测力、比较与调整；力控与贴砖共用反馈思想，但工艺参数分别设置 |
| 磨出好表面 | 选择砂纸／砂网粒度，比较轻压、重压与同点驻留，用侧光检查试片 | 认识粗砂痕、旋纹和过磨；磨损磨料不能靠加压补偿，损伤需重新批补 |
| 把粉尘收住 | 在剖视集尘器中识别滤芯堵塞、软管脱落或尘袋已满，停机隔离、处理后试运行 | 检查源头集尘、管路、尘袋、滤芯与密封；集尘异常时不能继续打磨 |
| 验收与养护 | 结合侧光、靠尺判读局部表面，再执行停磨、清余尘、断电、检查清洁、记录收纳 | 把实际表面复核与设备收工都纳入交接，不把路径走完或恒力读数当成质量结论 |

前端工具是打磨盘及其砂纸／砂网耗材，不是钻头。页面提供磨料、弹性接口垫与背盘分层说明。氧化铝是部分磨料产品采用的磨粒，具体材料、接口垫配置和粒度按产品资料确定。

圆盘旋转与进给可能形成弧形加工轨迹；明显深旋纹、划痕和露底需要处理。不同设备可采用旋转或偏心运动，本页的旋转显示用于解释轨迹。粉尘状态采用示意反馈，不能据此判断空气安全。

## 教学设定与边界

- 力学模型采用 `F = 5 × max(0, 4 + 墙面偏移 − 退让量)`，单位为 N 与 mm。默认目标 20 N，退让行程 ±4 mm，反馈时间常数 0.55 s，退让速率上限 4 mm/s，超过 45 N 锁定。全部数值均是本课模型设定，不是现场推荐力值或设备安全阈值。
- P80、P180、P240 用于比较粒度与表面效果，不代表统一作业配方，也不对应所引 Abranet Yellow 产品资料中的固定粗、中、细三档。
- 试片以离散状态演示起伏、划痕和损伤。轻压 P180 三遍后再用 P240 一遍可达到本关目标；遍数只服务教学规则，不预测真实去除厚度或施工效率。重压和驻留造成的损伤不能通过继续磨削消除。
- 机器人是教学概念机构，不对应特定品牌型号；毫米级法向位移放大显示。集尘器通过透明剖视展示内部，实际作业仍需完整防护和密封。三维粉尘和气流只用于解释路径，不表示浓度。
- 现场先核对腻子干燥及基层情况，处理裂缝、松动、空鼓和突出物，完成成品保护、人员隔离、空跑与急停检查。表面验收按项目要求结合靠尺、侧光及边角局部复核。清洗方式、滤芯是否可水洗等按具体设备说明书执行。

## 源码与构建

`src/page.html`、`style.css`、`hero.css`、`app.js` 负责单屏界面；`model.mjs` 与 `game.model.mjs` 提供接触力、试磨、控尘与养护纯模型；`robot3d.js` 构建机器人与逆运动学、柔顺腕、随动软管；`scene3d.js` 负责工坊、相机、墙面痕迹、气流与交互。构建内联公共 Three.js r160，离线不加载 CDN。详细设计见 [HERO.md](src/HERO.md)。

在项目根目录执行：

```powershell
node scripts/build.mjs 6-3 --audit
```

构建同时生成默认深色的 `index.html` 与兼容入口 `dark.html`，`--light` 参数亦可兼容使用。数据模型内联为 `M` 与 `Game`。不支持 WebGL 时自动提供二维备用视图，四关操作仍可完成。
