# 腻子打磨 · Hero 场景设计

一个蓝白色移动机器人通过肩、肘、腕的连续联动，让磨盘保持贴墙；同一接触模型驱动法向退让和力读数，作业结果留在真实三维墙面上。

采用与任务 6-4 同族的透视工坊、圆角实体、暖白墙面、蓝色设备和柔和接触阴影。主物体为一个机器人，集尘器整合在底盘上。桌面固定 16:9，无整页滚动；四项实训在同一个三维场景里切换。自由旋转、缩放、正面、侧面、磨头近看和耗材拆解均可直接操作。

目的性零件清单（装配级，重复紧固件按真实安装点生成）：

- 底座：下护板、圆角底盘、上盖、保险杠、四轮胎、四轮毂、四轮轴盖、轮轴、四轮安装座、底盘紧固件、铭牌、电池盖、散热槽。
- 操作：控制座、显示屏、屏幕框、急停底座、急停按钮、状态灯、指示灯座、旋钮、按钮。
- 肩部：肩座、旋转支承、肩关节芯轴、左右轴承盖、肩部紧固件、肩部防护罩、臂线入口。
- 上臂：承力连杆、蓝色外壳、白色盖板、端部连接座、肘轴、左右轴承、肘盖、肘部螺栓。
- 前臂：承力连杆、圆角壳体、白色盖板、腕座、腕轴、轴端盖、线缆导向座。
- 柔顺末端：固定法兰、导向杆、滑套、弹簧、传感环、伸缩杆、万向支架、双侧转轴、电机壳体、电机端盖、背盘、接口垫、砂网、集尘裙边、吸尘接口、夹环、孔圈。
- 集尘：桶体、桶盖、桶底、提手、搭扣、进气口、袋口、尘袋、滤芯、滤芯褶皱、风机盖、控制灯、检修窗、软管、两端管接头。
- 作业环境：厚墙板、踢脚线、地台、地板缝、侧墙、窗框、玻璃、保护膜、六个试磨区、侧光灯支架、灯体、靠尺、限位块。

动作：待机走刀预览不改变任务证据；用户实际操作控制力、磨料、工况、故障和养护。主动试磨保持头部贴墙、肩肘联动、砂盘旋转、软管随动；过压/驻留留下旋纹和损伤。粉尘只从接触点产生，通路恢复时向吸尘口收束。减弱动态效果或后台不可见时停止连续演示。

边界：机构为教学概念机，不冒充某品牌实机。法向毫米位移和表面痕迹放大显示；物理读数沿用本任务纯模型。Three.js 网格依靠深度缓冲而不是 SVG painter 排序，验证网格数量、端点、关节连接、动作帧、软管更换资源、相机各角度和浏览器实际截图，不将 SVG kit audit 作为该场景通过的证明。
