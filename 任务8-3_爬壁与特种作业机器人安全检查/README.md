## 来源与网页定位

依据[飞书本任务](https://my.feishu.cn/wiki/MaDFwaZpBiKYyrkg0wnc6UzQnNe#doxcnkgZJtJO6mwAJdCELg9xVZb)及[原文快照](../来源/14_8.机械机器安全维护.txt)。主线为吸附、供电、控制、履带与防坠之间的关系，以及作业前、上墙前、作业中、下墙后的检查。

适合做“爬壁作业条件推演台”：学生核对上墙准备，旁观动态故障，再选择停止移动、隔离下方和移交处置。主概念是吸附条件与独立防坠的互补，以及条件可能在作业中变化。原理剖面从[7-1](../任务7-1_巡检机器人_轮式_四足与爬壁/README.md)接续，本页侧重故障情境和处置条件。

## 值得做的交互点

| 知识点 | 学生动作 | 可见反馈与学习意义 |
| --- | --- | --- |
| 吸附方式与壁面 | 将负压或磁吸机型放到给定混凝土、玻璃、钢板示意壁面，查看条件卡 | 磁吸需要适用的铁磁性基材；负压需要相应密封与壁面条件。页面显示待核对条件，不能按墙面名字一键判安全 |
| 独立防坠路径 | 在剖面中分别查看风机电源路径和安全绳—可靠挂点路径 | 一条路径失效时另一条保持独立显示；安全绳未连接，即使负压稳定也提示准备缺项。强调防坠不是吸附系统的同义词 |
| AC/DC供电与牵缆 | 切换给定供电方案，播放线缆牵扯、接头异常、电量不足案例 | 供电图、风机状态和移动许可联动；备用电源显示为机型配置，不能与独立机械防坠合并成一个“保险”图标 |
| 上墙前的遗漏 | 翻看墙面、挂点、线缆、控制响应和下方人员的局部画面，选择暂停派工理由 | 未核实项目保持“未确认”；准备说明中可写证据不足，不将勾选数量或总分作为放行条件 |
| 作业中异常 | 在时间轴中选择漏气、掉粉、遥控迟滞、人员误入等事件，给出下一步动作 | 动画暂停移动、保持现有防护示意并高亮危险来源；不自动切掉维持吸附的供电，也不要求学生遥控强行下墙 |
| 下墙后与再次使用 | 在地面检查模型中点开密封圈、履带、线缆和绳具状态 | 损伤件保留待检修标记；复查前再次派工被提示条件缺失，理解一次检查合格不是持续保证 |

## 页面大致效果与代表样例

左边是 Facade-A、机器人及下方隔离区，右边为条件卡；供电和防坠路径可切换为简洁示意图。顶部四阶段标签允许直接选阶段，不强制闯关；故障播放可暂停回看，回看不抹掉上一阶段的未确认事项。

样例先展示“风机正常但安全绳未连接”，学生暂停派工。补齐教学连接后，机器人沿立面接近开口板缝，漏气箭头增多、压差状态下降。学生选择停止移动、限制下方通行并交由专业人员按设备应急方案处置；页面保持机器人受保护的定格画面。错误选择“立即切断全部电源”时，用因果示意解释可能同时失去风机吸附，随后回到选择前。

## 优先版与扩展

优先版做适用壁面、独立防坠路径、五类故障和阶段切换；扩展再加绳缆干涉、施工时壁面变化和管道/悬挂设备对照。负压值以“正常、变化、异常”的教学状态表现；设备手册来源明确后才能加入型号对应参数。安全绳弹性、制动和挂点承载不先做真实力学模拟。

## 能力边界

本页是条件推演，不产生工程放行书、证书或安全认证。磁吸/负压能力、防坠设计、挂点、气象及应急撤离都需按具体设备和工程确认。制作核对点：源文80%、90%、95%等条件不一致，不写为通用放行阈值；破损供电线缆应进入停用、专业检查处置分支，不能演示包扎后继续作业。模拟压力正常或“没滑落”均不证明现场可继续作业。
