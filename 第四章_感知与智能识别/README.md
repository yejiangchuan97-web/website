# 第四章 · 感知与智能识别

[打开章节总结入口](index.html)

沿“自身状态 → 环境扫描 → 图像识别”组织三个任务、五个实验入口。入口沿用第三章的蓝白展台风格，支持模型选择、拖动、巡展、暂停、全屏以及章节总结与学习导览。

| 任务 | 学习重点 | 实验 |
|---|---|---|
| 4-1 自身状态感知 | 对照坡面、起停、颠簸、转向与同步曲线 | [状态与数据](../任务4-1_机器人自身状态感知/index.html) |
| 4-2 激光雷达与点云 | 距离与坐标、遮挡与补扫、真实点云与截面 | [扫描与点云](../任务4-2_机器人激光雷达感知/index.html) |
| 4-3 安全帽与 YOLO | 画框与标签、预测筛选、真值核验 | [标注](../任务4-3_标注安全帽并应用YOLO模型/index.html#annotation) · [预测](../任务4-3_标注安全帽并应用YOLO模型/index.html#predict) · [评估](../任务4-3_标注安全帽并应用YOLO模型/index.html#evaluate) |

各实验每次进入默认深色，可在顶部切换主题或返回章节总览。视觉实验的三个视图在同一页面切换，保留本次操作；预测和评估使用内置教学结果，页面不运行真实 YOLO 推理。任务之间不共享实验数据。

在仓库根目录运行 `node scripts/build.mjs 4` 构建入口与全部任务。公共导航由 `公共资源/感知与识别/chapter-layout.mjs` 内嵌，各任务仍为离线 HTML。入口样式复用第三章基础 CSS，额外样式位于本章 `src/style.css`。

运行 `python scripts/package-chapter4.py --output <输出目录>` 生成独立站点与 ZIP；打开 `site/index.html` 即可使用。
