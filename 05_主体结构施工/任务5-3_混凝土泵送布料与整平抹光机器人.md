# 任务5-3 混凝土泵送布料与整平抹光机器人：工序协同与标高反馈

## 原文依据与网页定位

依据[飞书原文对应任务](https://my.feishu.cn/wiki/UtqMwe7yti9zuJkBlLrcywi7nJe#doxcnUJuNK1D3ih5VKdcUdItnLc)，快照见[来源11](../来源/11_5.主体结构施工协同.txt)。锚定泵送、布料、振捣、粗平、精平与抹光，激光基准—接收器—控制—液压调平，以及振捣的人工判断。双缸泵送剖面为泵送机械原理的辅助展开，不改变原任务范围。

**适合做多设备协同三维动画，配一块标高控制小实验。** 主页面“Floor-A浇筑协同现场”可以从设备剖面、工序看板或整平反馈任意进入。泵车、布料设备、人工振捣、整平与抹光各有不同交互，不用同一种控件替代工序差异。

## 可以做的交互点

| 知识点 | 用户操作与视觉反馈 | 学习意义 |
| --- | --- | --- |
| 工序和分工 | 将工序卡放到楼面不同区域，单击泵送/振捣/整平时高亮承担设备及前置条件；回放分区接续 | 各环节解决不同问题；整平效果不能替代振捣密实，也不等于养护完成 |
| 双缸泵送 | 在透明剖面单步观察一缸吸料、一缸推料及切换阀，着色区分进入/排出；可切自动循环 | 将活塞、液压驱动和物料输送联系起来；切换不是让两缸同时随意吸排，具体阀型另查手册 |
| 布料与覆盖 | 拖动布料末端到分区，播放铺料轨迹与设定厚度色带，查看钢筋密集/边角区域 | 输送到楼面和均匀铺开是两个任务；色带只表示设定分布，不声称流变计算真实 |
| 人工振捣协同 | 点选可进入位置和密集钢筋阻挡点，查看对应现场片段/教学气泡示意，圈出需人工判断区域 | 位置、混凝土状态、阻力和时间共同影响过程，不能凭一个动画气泡数自动判断密实 |
| 标高闭环 | 设置激光基准并注入一处高/低起伏，单步看接收偏差—控制方向—油缸—刮板高度，比较关闭反馈 | 理解整平靠参照与执行调节；基准误设时整个控制可稳定地做错标高 |
| 抹光与时间窗口 | 从预置的“过早/适宜/偏晚”材料状态回放表面变化，框选边角人工区 | 材料状态、工艺时机与覆盖有关，走过一遍不代表表面质量合格 |

## 页面布局与代表效果

中央为同一教学楼Floor-A楼面，右侧提供设备近景和整平反馈图，底部工序条显示各分区当前阶段。左侧仅在选中设备后展开其专用控件，例如泵送看阀切换、整平看基准偏差，不给所有设备共用一组参数滑块。基准高度在世界Z方向以米存储，局部标高误差以毫米显示，换算过程可查看。

例一双缸泵的吸料与推料交替循环，暂停到换向瞬间，学生辨认哪个缸接料斗、哪个缸接输送管。例二Floor-A局部有设定凸起，关闭反馈时刮板留下标高差，开启反馈后出现调整过程；将激光基准整体设错，表面可以变平却仍偏离设计标高，说明“平”与“标高正确”需分开核对。

## 首版与扩展

先做工序分工、泵送剖面、整平闭环三项；振捣用真实片段与简化示意对照，抹光先回放工况。扩展再加入分区协同冲突、输送管占用Route-A和不同传感方式比较。不开发混凝土流体求解或施工调度优化，避免几何动画制造真实密实度和强度结果。原文精度例值仅作原文识读，页面实际阈值需对应设备/项目资料。

## 能力边界

网页展示协同关系、液压几何和简化反馈，不生成泵送压力许可、振捣合格结论或混凝土强度。真实设备架设、泵管承压、人员位置、材料状态、验收与养护均需现场依据；不能因整平动画结束就自动宣告楼面可以交付下道工序。
