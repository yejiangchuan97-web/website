# 任务5-1 钢筋加工机械与绑扎作业面识读：从半成品到可作业区域

**已制作：[打开大型三维教学沙盘](教学演示/5-1.html)** · [使用说明](教学演示/使用说明.md)

演示包含可独立进入的场地识读、机械原理、作业条件和加工偏差四个主题。学生可以定位六处关键位置、慢放三台机械、比较同一交点的A/B机位、叠加目标轮廓，并选择质量复核方法和导出观察实验单。场景与尺寸均为原创教学设定。

## 原文依据与网页定位

依据[飞书原文对应任务](https://my.feishu.cn/wiki/UtqMwe7yti9zuJkBlLrcywi7nJe#doxcn0806AVCz2motDJFnl1RGVh)，快照见[来源11](../来源/11_5.主体结构施工协同.txt)。锚定调直、切断、弯曲的输入输出，梁板边线、柱边、洞口、交点、堆料和人员通道，以及完整性、间距、松扣和保护层检查。

**适合做“机构剖面＋作业面分区”网页。** 主页面“Rebar-A加工与进场观察台”，加工动画和钢筋网俯视图可以分别使用。核心看点是上游误差如何传到交点与可达性，不用一段统一流程把所有交互串成闯关。

## 可以做的交互点

| 知识点 | 用户操作与视觉反馈 | 学习意义 |
| --- | --- | --- |
| 调直原理 | 拖动钢筋穿过交错调直轮，剖面慢放反向弯曲；比较盘圆、波浪状与平直半成品 | 看清输入、工作机构和输出，调直不足会造成放样及交点位置变化 |
| 切断与弯曲 | 在料单选择目标长度/弯折形状，单步观察夹持、刀片切断、弯曲轴绕中心轴转动；叠加目标轮廓 | 区分动作完成与加工尺寸合格；工序先后随设备工艺选择，不把唯一顺序强加所有设备 |
| 上游误差传递 | 将“偏短、弯角偏差、残余弯曲”半成品拖到Rebar-A，叠加设计位置与设定偏差 | 保护层、搭接/交点与定位会受影响；不是只变颜色提示“错了” |
| 作业面识读 | 点击俯视图的边线、柱、洞口、材料区与Route-A通道；切到剖面核对层次与垫块 | 平面上一个清楚交点不保证工具有进入空间，边界和安全条件同样重要 |
| 交点可达性 | 移动机器人基座，显示工具接近轴、简化工作空间、工具包络与障碍；框选连续绑扎区 | 正常大面、密集节点和洞口边分别需要连续作业、人工配合或隔离；只看TCP可到不足以判断可作业 |
| 质量与复核方法 | 开启漏绑/间距/垫块问题图层，量取相邻钢筋距离；点击松扣显示应采用人工接触检查 | 将目视、量具、垫块核查和人工检查匹配问题，网页外观不直接证明牢固度 |

## 页面布局与代表效果

左侧为加工设备卡片与料单，中间可切“三维剖面/楼面俯视”，右侧显示选中构件的设计值、设定值、检查方式。下方是设计钢筋网与加工后钢筋网的并排局部放大。钢筋几何使用毫米输入，放入世界米制场景时显式换算；洞口和人员通道始终可见。

演示一将一根弯角偏差的半成品放到网格边角，设计交点与实际交点错开，绑扎头无法按原点位对准；学生可回到弯曲剖面寻找来源。演示二在同一规则网格中插入一处密集柱节点和洞口，用户划区后切换机器人的接近路径，看“能到达一个点”与“能安全连续绑扎一片区域”的差别。

## 首版与扩展

先做三台机械的几何剖面动画、Rebar-A楼面分区与一组误差对照；可达性首版采用明确标示的简化包络和碰撞几何。扩展再加入料单导入、多层钢筋剖面与复杂交点可视化。不要在首版计算钢筋回弹、真实切削力或材料破坏；料单、弯曲半径和允许偏差来自教学原材料、项目设计及设备手册，页面不给通用合格阈值。

## 能力边界

统一教学机器人用于展示换工具和到点关系，不代表任一真实底盘可以直接踏行钢筋网。几何可达和动画平直不等于承载、加工及结构质量合格；保护层、牢固度和安全边界仍需按现场设计与检查方法复核，教材网页不替代施工验收。
