## 可以做的交互点

| 知识点 | 用户操作与视觉反馈 | 学习意义 |
| --- | --- | --- |
| BIM数据与单位 | 读写墙ID、长高、中心坐标、法向、洞口及单位，选字段时高亮对应几何；错单位提示尺寸异常 | 先把数据变成可核对的对象，模型与现状版本不同须提示，不能直接下发 |
| 墙面展开与路径 | 拖动二维洞口，生成蛇形作业线，逐条显示洞口裁剪、绕行及喷枪关闭段；二维点选定位三维 | 线穿过洞口时应分段停喷/绕行，路径几何与喷涂开关不可混为一项 |
| 间距、喷幅与覆盖 | 在固定教学喷幅下比较不同道间距，显示重叠带和未覆盖带；查看起收喷与转弯足迹 | 路径线走遍不等于喷幅覆盖充分，边界和启停影响局部搭接 |
| 喷距、姿态与速度 | 三维显示喷枪TCP、墙法向、喷射锥/扇形和设定距离；慢放经过转角及减速段 | 正确姿态与距离需沿路径保持；同一路径的驻留时间不同会改变设定沉积示意 |
| 参数与材料状态 | 对照压力/距离/速度设定及过滤、喷嘴、基层案例，旁边展示对应样板图片 | 同一流挂/露底现象可以多因，不能把图像效果直接当单一参数的真实物理预测 |
| 缺陷诊断 | 点选流挂、露底、颗粒、条纹，选择需要核对的材料/喷嘴/压力/路径证据，显出原因关系图 | 支持有依据的排查，不预设看到缺陷就补喷或一律归因机器人 |
| 接力与清洗 | 在墙展开图划两段交接区，对照参数与边界；拆看喷嘴—滤网—管路残料位置 | 交接处需重点复核，清洗状态影响下一次喷涂；清洗顺序和介质以设备材料要求为准 |

## 页面布局与代表效果

左侧为可读字段表及简短JSON视图；中间上方是三维机器人/墙体，下方为二维展开；右侧为喷幅、覆盖统计与缺陷样板。使用同一Wall-A门窗、TCP与对象ID，世界Z向上米制，喷距/喷幅显示毫米。覆盖图分几何未覆盖、覆盖次数和教学沉积示意三层，避免用一张热图冒充实际膜厚。

例一沿用原文“间距50厘米”的问题情形，配上明确标示的教学喷幅，观察是否留下漏带；更换喷幅后重新判断，不把50厘米固定解释为所有喷枪均不合格。例二移动窗洞但保留旧模型路径，三维喷涂污染设定窗框区；同步现状洞口后，路径裁剪与关闭喷枪段随之更新，展示版本核对的意义。

## 能力边界

三维扇形、覆盖率与色带用于几何和参数关系说明，不是真实雾化、膜厚、附着力或工程验收结果。基层干燥、VOC/喷雾防护、管路压力和清洗要求必须现场确认；本页不输出真实设备可执行程序。
