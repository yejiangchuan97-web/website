## 三个学习站

1. **人工砌筑挑战**：转砖区分顺砖、丁砖与侧砌；在空位逐块拼出240 mm与365 mm墙厚；调整上下皮组砌、偏移与灰缝，检查真实接缝。支持错误反馈、撤销、重试和进度；修改通过后的方案需重新检查。
2. **施工难点实验**：调节通缝、灰缝厚度差、基准偏移。右侧对应说明机器人可承担的动作和仍需人工判断的事项。
3. **机器人共性原理**：同一实体机构展示XYZ定位、绕竖轴转向、夹持与反馈。支持固定/移动支承、8阶段慢放、时间轴、单步、夹具壳盖展开，以及18 mm基准偏差与重新测量实验。

三维画面支持拖动旋转、缩放、俯视、正视和近看。移动端按画面、控制的顺序纵向排列；键盘可操作视角与所有表单。减少动态效果时，播放改为离散步进。没有WebGL时使用Anatomy工具包生成的实体投影备用画面，仍可完成游戏与时间轴操作。

## 教学依据和边界

- 砖样为240 × 115 × 53 mm；10 mm灰缝仅是本页几何设定，不是所有材料的统一验收标准。
- 24墙示例厚240 mm；一砖半墙为240 + 10 + 115 = 365 mm，常称三七墙。用户口头“三六墙”在本页按一砖半墙解释，不直接建成360 mm。
- 顺砖/丁砖指长边与墙长方向的关系；平砌/侧砌指承托面。本例一顺一丁采用四分之一排砖模数62.5 mm，不能推成所有砖型的统一搭接要求。
- 墙样是直墙中部的观察窗口，边缘截断不作为完整墙端、转角、洞口或收口做法。单皮墙厚试排完成不等于整个组砌方案合格。
- 机器人是可观察共性关系的教学机构，不对应商品机型。固定与移动支承变化用于说明站位和重新建立基准，未模拟自主导航。力控、激光或视觉均不是所有设备的必备配置。
- 本页机器人使用预铺灰床。真实设备可能使用普通砂浆、薄层砂浆或专用胶黏剂，且砌块尺寸、供料方式与人机分工不同。
- 误差是教学设定，不是实测。几何位置复测不等于砂浆饱满度、强度、垂直度或实体工程验收通过。

## 构建和验证

在仓库根目录运行：

```text
node scripts/build.mjs 6-1
node --test "任务6-1_砌筑工程_人工工艺_砂浆机械与机器人进场/qa/manual-model.test.mjs" "任务6-1_砌筑工程_人工工艺_砂浆机械与机器人进场/qa/robot-model.test.mjs" "任务6-1_砌筑工程_人工工艺_砂浆机械与机器人进场/qa/rebuild/issues-model.test.mjs"
node "任务6-1_砌筑工程_人工工艺_砂浆机械与机器人进场/qa/rebuild/browser-check.mjs"
```

`src/manual-model.mjs`、`robot-model.mjs`、`issues-model.mjs`提供唯一数据模型；`scene3d.js`负责真正三维实体；`fallback.js`使用Anatomy投影工具；`manual-game.js`与`app.js`负责交互。

造型遵循Anatomy的实体部件、四向明暗、真实支承、细节、单一运动重点及克制运动原则。考虑整台设备与砖墙的自由视角，主渲染器沿本仓库既有三维页面采用本地Three.js深度缓冲渲染；不把它描述成Anatomy beta turn引擎，也不将模型和浏览器测试宣称为SVG recorder或turn全几何审计。

当前检查记录见[qa/rebuild](qa/rebuild/)，部件与几何说明见[scene-parts.md](qa/scene-parts.md)。旧版`src/geometry.mjs`、`src/model.mjs`、`src/order.mjs`及旧版QA留存作历史参考，不参与当前构建。修改前页面另已保留本地副本。
