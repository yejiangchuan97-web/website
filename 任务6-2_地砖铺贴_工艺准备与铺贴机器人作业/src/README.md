# 任务6-2 · 地砖铺贴机器人实验室

双击 `../index.html` 可离线打开；`../dark.html` 以深色主题打开。页面内可切换主题。桌面采用16:9固定单屏布局；手机通过底部按钮切换模型与实验面板。

## 内容

1. 视觉对位：平面双轴误差，比例纠偏，反馈开关及观测遮挡。
2. 吸附搬运：四吸盘理论吸力、载荷需求、独立隔离的单吸盘失效、起吊联锁与搬运中失效停机；含慢放、暂停、单步、复位。
3. 压实标高：基层/胶层/砖厚叠加，相同压力下的不同完成面，预设缺胶剖面对照。

不覆盖整房排砖、真实胶料流变、全型号机器人控制或实体空鼓检测。场景是通用XYZ铺贴机构的等效教学台，气路隐藏于梁体内。尺寸与控制阈值均为教学值；来源详见页面“原理与来源”。

## 构建与检查

- `node build.mjs`：重建几何与两个独立HTML，使用已验证的动作公共遮挡顺序。
- `node build.mjs --ui`：只更新界面与行为，复用几何缓存。
- `node ../../qa/tiling/settle-motion.mjs`：对初始、动作关键/中间姿态及视觉极限测量真实重叠，合并求解公共绘制顺序；逐姿态运行anatomy审计。更改几何后先运行此项，再运行 `node build.mjs --ui`。
- `node ../../qa/tiling/extremes.mjs`：检查压实区间两端，胶床与主砖相接。
- `node ../../qa/tiling/verify.mjs`：物理关系、状态联锁、全屏、主题与15组布局检查。
- `node ../../qa/tiling/visual.mjs`：以Playwright启动本机Edge，执行anatomy原始LINE_ENDS检查器；浅/深主题共14个静止姿态。原始capture/drive启动器在本机Edge上启动即退出，故复用其检查算法。
- `node ../../qa/tiling/closeups.mjs`：4×整机与末端细节截图。

原始kit位于 `../../公共资源/装饰装修施工/assets/tiling-anatomy`，保留MIT许可。最终HTML内联所需样式、模型与绘图代码，无CDN或网络运行依赖。QA脚本中的浏览器和Playwright路径依赖开发机器，不影响交付页面。
