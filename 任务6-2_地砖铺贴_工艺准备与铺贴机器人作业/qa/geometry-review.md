# 任务 6-2 几何检查记录

检查日期：2026-10-22。范围仅为 anatomy 铺贴台、可替换吸盘末端及其运动，不代表新版教学活动的整页集成检查。

## 实现

- 单大盘、双中盘、四小盘分别为 58、65、71 个实体零件。
- 有效盘径设定为 160、约 113.1、80 mm，总有效面积相等。主台盘径倍率为 2 : √2 : 1，盘体适度放大以便观察，不宜从主图量取实际尺寸。
- 单盘中心支杆直接接至分配座；双盘使用短支承梁；四盘使用双纵梁。实体几何、支承接触和深度顺序分别记录并求解。
- `setRigPose` 统一更新平移、升降杆、砖块和材料床。主台不模拟绕 Z 轴转角，角度由俯视检查窗表现。
- 故障盘与模型一致：四盘为 +X/+Y，双盘为 +X，单盘为中心盘；变暗显示，保持实体可见。

## 验证结果

1. 三种布局分别检查初始姿态、搬运 t=0/1/1.5/2/2.5/3/3.5/4/5、两个平移边界、抬高姿态，共 39 个姿态。所有 anatomy 审计项目为 0，均以 `audit passed` 结束。跨姿态绘制顺序为 0 interlocks、0 dropped rules。
2. 三种布局追加 top=6、12.8，bed=top−4 的材料床与砖面接触极限，共 6 个姿态，均通过审计。
3. 浅色、深色各检查三种布局的 12 个姿态，共 72 次 line-end 检查，均为 `line ends: 0`。运行中关闭 WebGL；本图为纯 SVG，无 WebGL 依赖。
4. 读取并检查六张 4× 图：单、双、四盘的浅色与深色图。检查吸盘/支杆/支承梁/分配座、升降杆与外壳、滑台导轨、立柱底座、相机支架和砖层边缘。未发现悬空接合、穿插、错误遮挡或纹理断端。
5. 几何页面控制台为 clean。此轮图片使用检查时的页面框架；新版活动的布局与交互由后续整页检查覆盖。

## 重跑

在仓库根目录运行：

```text
node 任务6-2_地砖铺贴_工艺准备与铺贴机器人作业/qa/settle-motion.mjs
node 任务6-2_地砖铺贴_工艺准备与铺贴机器人作业/qa/extremes.mjs
node scripts/build.mjs 6-2 --ui
node 任务6-2_地砖铺贴_工艺准备与铺贴机器人作业/qa/visual.mjs
```

`settle-motion.mjs --layout=single|dual|quad` 可分布局运行；全部通过后用 `--assemble` 汇总。分布局缓存包含几何和姿态签名，过期缓存不能汇总。未修改几何时，`--ui` 使用已求解的场景缓存；修改几何后重新运行几何审计。
