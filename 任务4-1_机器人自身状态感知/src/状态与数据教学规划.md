# 任务4-1：从施工状态读懂传感数据

## 本轮课程定位

面向土木工程学生。教学对象是机身状态及其数据特征，不讲芯片、电路、封装、编码器结构或电流检测。沿用 anatomy 的实体、深度、时间一致性与可操作原则，将三维对象用于表现坡面、底盘、路线和动作；数据始终与场景同屏。单个既有 Hero 场景重构，不扩展成完整施工场站。

## 四个案例

1. 坡面停驻：调整前后/左右坡角，读静态估计倾角和含重力的三轴加速度。静止在斜面时合量仍约9.81 m/s²。缓慢调坡过程忽略运动加速度；坡面角度是模型参照，显示倾角从三轴关系估计。
2. 起步与制动：以固定的起步、匀速、制动、停车时间段回放。显示前向线加速度、速度与位移。前进方向为正，制动为负；匀速时加速度为零；停车后位移不回到零。速度、位移明确为设定参照，不冒充加速度的直接读数。
3. 路面颠簸：同一速度经过平整、轻微起伏、明显起伏的道路。模型规定短段正弦起伏与垂向随动，位移及其解析二阶导数驱动动作和读数。比较统一坐标下的垂向线加速度；只有路面条件变化，其他条件不变。竖向位移视觉放大8倍，曲线保留真实教学数值；简化为车体中心随路面竖向运动，不模拟悬架及逐轮动力学。
4. 原地转向：慢转/快转都转90°。并列角速度与累计转角，停止后角速度归零而方向保持。角速度用°/s帮助直观理解；CSV保留单位，补充说明其常见rad/s单位。

## 阅读路径与交互

选择状态 → 回放/拖动共同时间游标 → 同屏观察三维姿态和读数 → 点击关键片段 → 改变一个条件并叠加固定基准曲线。曲线默认完整展开、全程预览、当前时刻圆点标记；可点击或拖动任一曲线定位时刻。避免数值独立于模型、相同单位坐标随对照自动变化、未经标明的视觉放大。

手机加速度CSV仍为独立扩展，缺轴保持缺失，不能从任意原始数据反推三维姿态。保留当前条件、全程样本与观察文本的记录和CSV导出。

## 三维组成（建模前）

不建传感器内部。复用轮式机器人外观，封闭罩壳和方向标记；约100个有用途的实体：路面底板1、边缘条2、伸缩缝条4、里程标尺条2及刻度24、起终点标记2；底盘1、壳体1、顶盖1、前后保险杠2、侧裙2、检修缝4、盖螺钉4、轮胎4、轮毂4、轴帽4、轮毂螺栓24、胎纹48、前向标记1；坡面与水平参照1组、转向参照圆1组。姿态角弧与方向线明确是数据参照，而非实体零件。

## 数据及验收

纯模型输出姿态、位置、速度、加速度和阶段文本，三维、读数和曲线共同消费同一采样。按解析导数检查速度/位移/加速度；静止重力合量检查；快慢转积分均90°；颠簸高低条件比例与去重力区别检查。浏览器验证四场景、曲线寻址、条件对照、减少动态、键盘、记录及CSV导入导出。检查桌面和390px布局、浅深主题、三维首次静置显示和无WebGL兼容图。
