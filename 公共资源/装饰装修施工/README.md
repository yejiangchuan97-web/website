# 装饰装修施工 · 教学演示

打开 [任务6-4 喷涂机器人实验室](../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/index.html)。独立HTML，无需联网或安装依赖；直接用现代浏览器打开。另有 [深色初始主题](../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/dark.html)，页面内也可切换。

三个实验分别聚焦：

1. 喷幅与搭接：改变喷距和道间距，比较400 mm喷幅配200/500 mm间距的覆盖差异。
2. 洞口与停喷：比较完整喷幅保护、只判断中心、不停喷三种逻辑，定位窗边关键帧，对照污染与未覆盖区域。
3. 速度与沉积：观察起收段减速时的相对量，比较定流量和流量随速度同比调整。

点击右上角全屏或按F；顶部切换课程，空格播放暂停，左右方向键单步，进度条定位。喷头近看随工具移动。系统启用减弱动态时停止自动播放，可单步查看。手机用底部按钮切换模型/控制，无需滚动。

几何覆盖是完整计划的20 mm网格估计，扣除窗洞；不是已施工面积。相对沉积来自固定传递效率下的流量/速度简化关系，不预测真实膜厚或缺陷。参数为教学设定；页面“教学说明”包含来源和模型约定。

## 源码与复建

`../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/src` 包含教学模型、几何、界面和构建脚本；`../anatomy` 是MIT许可的Anatomy本地工具包。最终HTML已内嵌依赖。

从项目根目录运行：

```text
node 任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/src/build.mjs --audit
```

修改几何后先执行 `../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/qa/order.mjs`，重新生成多姿态共同遮挡顺序，再构建。`../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/qa/verify.mjs` 检查教学计算、四种桌面尺寸、手机、回放、全屏和交互；`../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/qa/lines.mjs` 使用Anatomy原始线端检查器。浏览器验证脚本使用本机Playwright运行环境和Edge路径，可按本机安装修改。

Anatomy原有截图启动器在本机Edge提权环境下无法启动，本项目以Playwright传入 `--do-not-de-elevate` 捕获截图，并调用相同的线端检测函数。检查报告与截图保存在 `../../任务6-4_室内喷涂_路径规划_参数控制与缺陷诊断/qa`。
