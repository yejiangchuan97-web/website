## 原文与主网页

来源：[飞书任务原文](https://my.feishu.cn/wiki/NrlbwvO3Xij3kLksAg9c7h6YnJe#doxcnMn7GdKJwAxxrwHOPxGxsQd)。锚定J1—J6、位置与姿态、关节／基／工具三种点动参照、点动前条件确认；原文拓展提到示教点与PTP/LIN。用户关心的CIRC及工件坐标作为明确标注的辅助扩展。

主资源是**六轴识读与点动沙盒**。三种点动参照各有独立演示，学生可直接按轴、对比方向或挑选错误情境；“坐标参照”与“路径指令”分在不同面板，避免把基坐标误当LIN、工具坐标误当CIRC。

## 页面效果

中央是Wall-A前的同一移动六轴模型，底盘停住，默认装斜向喷嘴。左侧J1—J6按钮对应轴线与关节滑条，右侧可选基坐标、工具坐标的平移／转动按钮；顶部显示当前工具。角落固定小窗显示世界、基、工具轴，用户可只看一个坐标系，也可并排比较。

世界Z向上，基座以安装变换定位于世界；旋转底盘朝向时基轴随安装关系变化。基坐标点动不能让底盘自己移动，底盘行走另接任务3-5。界面长度用mm、角度用°，内部统一单位。

## 可以开发的交互点

1. **J1—J6逐轴辨认。** 按住某轴的正负按钮或拖小范围滑条，该轴与下游连杆突出显示，其他关节角固定；J1带动后续整臂、J2大臂、J3小臂、J4/J5腕部、J6法兰。同时画TCP轨迹，让学生看出“前3轴送位置、后3轴调姿态”只是初步记忆，后轴转动在偏置工具下也会移动尖端。夹爪开合另设工具按钮，不算J7。
2. **关节角改变，不保证尖端走直线。** 给J3一个小角增量，TCP画出曲线；切到保持姿态的基坐标上移，多个关节同步变化而TCP沿基轴移动。两段并排慢放，理解关节点动与笛卡尔点动直接指定的量不同。
3. **基轴与工具轴方向对照。** 默认喷嘴倾斜，学生各点一次“基+Z”和“工具+Z”，分别显示世界中的移动箭头与轨迹。工具进给轴在模型中明确指定，不能只凭工具名称假定某轴沿喷嘴；若两个方向恰好重合，画面说明重合原因，不强行做成总是不同。
4. **位置与姿态可以分别观察。** 点击“尖端位置保持、改变朝向”的已验证小运动，法兰和关节会配合改变；再看“只转J5”的片段，偏置尖端随之移动。通过真实几何区分TCP绕自身旋转与单轴机械转动，不以摄像机绕模型转动冒充机器人姿态改变。
5. **条件不完整时先识别原因。** 情境卡可单独放入“工具刚换”“学生位于扫掠区”“参照未确认”。点动按钮旁显示缺项，学生点错项后解释为什么提高速度、只看尖端解决不了问题。页面的低速与停止按钮是仿真交互，不规定真实机器人的统一安全速度。
6. **坐标参照与路径类型两层选择。** 扩展的示教点小窗提供同一起终点，切PTP看关节空间组织的运动，切LIN看TCP直线，加入非共线经过点后看CIRC圆弧；坐标系负责解释点与方向，路径类型负责怎样走。圆弧不直接由“工具坐标”产生，直线也不由“基坐标”自动保证无碰撞。三种示例使用已验证的连续关节轨迹，不以端点间插值假装机械臂运动学。
7. **坐标框之间的关系。** 辅助扩展增加“世界、基座、工件／用户、法兰、工具”可切换参照框。拖底盘位置或朝向，基座框随底盘改变，法兰与工具框也在世界中改变；若关节角及工具刚性安装不变，基座到法兰、法兰到TCP的关系保持。工件框固定在Wall-A时不会跟底盘跑，选择同一孔位可看到它在世界／工件中的位置不变、在基座中的表达改变。法兰框位于接口，工具框原点在TCP，方向按工具定义；这项关系观察是对原文三种点动的扩展，不冒充原文已完整讲授五种坐标系。
